# 스트리밍(Streaming) 기초

## 1. 스트리밍의 필요성
- **정의**: 대량의 데이터를 한 번에 전송하지 않고, 작은 조각(청크)으로 나누어 지속적으로 전송하는 기술
- **필요성**:
  - **실시간성**: 사용자 대기 시간 최소화 (첫 번째 토큰까지의 지연 감소)
  - **메모리 효율**: 전체 응답을 메모리에 보관하지 않아도 됨 (대용량 처리 가능)
  - **사용자 경험(UX)**: 진행 상황을 시각적으로 보여줌 (타이핑 효과, 진행률 표시)

## 2. 기본 스트리밍
- **개념**: 서버에서 클라이언트로 데이터를 청크 단위로 순차적으로 전송하는 가장 기본적인 형태
- **동작**: HTTP/11 청크 전송 인코딩, WebSocket, SSE(Server-Sent Events) 등 활용
- **특징**: 단순한 단방향 또는 양방향 데이터 흐름

---

## 3. 모델 직접 스트리밍
- **개념**: AI/ML 모델(예: LLM)의 추론 결과를 생성되는 즉시 토큰 단위로 출력
- **동작**: 모델의 디코더가 매 스텝맱 생성한 토큰을 바로 전송 (전체 시퀀스가 완성될 때까지 기다리지 않음)
- **예**: OpenAI API의 `stream=True` 파라미터

---

## 4. 체인 스트리밍
- **개념**: 여러 처리 단계(체인)를 거치는 워크플로우에서 각 단계의 중간 결과를 스트리밍
- **동작**: 예) 검색 → 요약 → 번역 체인에서 검색 결과, 요약문, 번역문이 각각 완료되는 대로 전송
- **특징**: 파이프라인 전체 지연을 분산시켜 보여줄 수 있음

---

## 5. 비동기 스트리밍
- **개념**: 비동기 I/O (Async/Await, 이벤트 루프)를 활용하여 블로킹 없이 여러 스트림을 동시에 처리
- **동작**: 하나의 스레드로 다수의 클라이언트 요청을 처리하거나, 백그라운드 태스크로 데이터를 생성하면서 전송
- **장점**: 자원 효율성, 높은 동시성

---

## 6. 에이전트 스트리밍
- **개념**: AI 에이전트(도구 호출, 계획 수립, 실행)의 행동 과정을 단계별로 실시간 전달
- **동작**: "도구 호출 중", "생각 중", "최종 답변 생성 중" 등의 상태와 결과를 스트리밍
- **예**: LangChain Agent의 `astream_events()`

---

## 7. 멀티 모드 스트리밍
- **개념**: 텍스트, 오디오, 비디오, 이미지 등 다양한 형식의 데이터를 동시 또는 인터리브(interleave) 방식으로 스트리밍
- **동작**: 예) 텍스트 설명과 함께 관련 이미지가 순차적으로 등장, 음성 합성 결과를 텍스트와 동기화
- **프로토콜**: WebRTC, HLS, DASH 등

---

## 8. 커스텀 스트리밍
- **개념**: 표준 스트리밍 방식으로 제공되지 않는 특수 로직(예: 사용자 정의 필터링, 집계, 변환)을 직접 구현
- **동작**: Generator, AsyncGenerator, 커스텀 콜백, 상태 머신 등을 이용해 스트림을 조작
- **목적**: 비즈니스 로직에 맞춘 정밀 제어 (예: 특정 키워드가 나오면 스트림 일시 중지)

---

## 📊 각 스트리밍 방식의 장단점 및 응용 분야 비교 표

| 방식 | 장점 | 단점 | 응용 분야 |
|------|------|------|-----------|
| **기본 스트리밍** | 구현이 단순, 모든 플랫폼에서 지원 | 흐름 제어 한정, 재전송/복구 기능 부족 | 실시간 로그, 알림 피드, 주식 티커 |
| **모델 직접 스트리밍** | 첫 응답 속도 빠름, UX 향상 | 모델과 네트워크가 강결합, 에러 처리 복잡 | 챗봇, 실시간 번역, 자동 완성 |
| **체인 스트리밍** | 중간 결과 확인 가능, 투명성 높음 | 체인 설계 복잡, 지연 누적 가능 | RAG 파이프라인, 문서 처리 워크플로우 |
| **비동기 스트리밍** | 높은 동시성, 자원 효율적 | 디버깅 어려움, 콜백 헬 가능성 | 대규모 API 서버, IoT 데이터 수집 |
| **에이전트 스트리밍** | 에이전트 행동 추적 가능, 신뢰도 향상 | 상태 관리 복잡, 토큰 소모 큼 | 자율 AI 비서, 자동화된 의사결정 시스템 |
| **멀티 모드 스트리밍** | 풍부한 사용자 경험, 복합 콘텐츠 제공 | 동기화 이슈, 대역폭 소모 큼 | 실시간 화상 회의, 게임 라이브, AR/VR |
| **커스텀 스트리밍** | 비즈니스 요구에 최적화, 유연성 최대 | 개발/유지보수 비용 높음, 표준과 호환 어려움 | 금융 거래 모니터링, 맞춤형 데이터 파이프라인 |

---

> **종합 정리**: 스트리밍은 실시간성과 사용자 경험을 위해 필수적이며, 단순 전송부터 AI 추론, 복합 멀티미디어, 에이전트 행동 추적까지 그 범위가 확장되고 있습니다  
> **선택 기준**:  
> - *빠른 응답*이 중요하면 **모델 직접 스트리밍**  
> - *복잡한 파이프라인*을 보여주려면 **체인 스트리밍**  
> - *대규모 동시 처리*는 **비동기**  
> - *에이전트 신뢰성*이 핵심이면 **에이전트 스트리밍**  
> - *다양한 미디어*는 **멀티 모드**  
> - *특수한 요구사항*이 있다면 **커스텀 스트리밍**을 고려하세요
