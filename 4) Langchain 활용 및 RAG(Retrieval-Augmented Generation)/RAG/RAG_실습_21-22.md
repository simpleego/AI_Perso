# 3단계 벡터 DB 검색 → 4단계 프롬프트 구성

핵심 흐름은 다음과 같습니다.

```text
문서 준비
→ 문서 임베딩
→ ChromaDB 저장
→ 사용자 질문 임베딩
→ 유사 문서 검색
→ 검색 문서 + 질문으로 프롬프트 구성
```

## 3단계: 임베딩 함수 만들기

```python
def get_embedding(text):
    """
    입력 문장을 OpenAI 임베딩 벡터로 변환하는 함수
    """
    response = client.embeddings.create(
        model="text-embedding-3-small",
        input=text
    )
    return response.data[0].embedding
```

## 4단계: 예시 문서 준비

```python
documents = [
    "육아휴직은 최대 1년까지 사용할 수 있습니다.",
    "육아휴직 급여는 고용보험에서 지급됩니다.",
    "육아휴직 중 승진은 제한되지 않습니다.",
    "배우자 출산휴가는 10일 사용할 수 있습니다.",
    "연차휴가는 근로기준법에 따라 부여됩니다.",
    "출산전후휴가는 총 90일 사용할 수 있습니다."
]

ids = [
    "doc1",
    "doc2",
    "doc3",
    "doc4",
    "doc5",
    "doc6"
]
```

---

## 5단계: 문서를 임베딩해서 ChromaDB에 저장

```python
import chromadb

# ChromaDB 클라이언트 생성
chroma_client = chromadb.Client()

# 기존 collection이 있으면 삭제하고 새로 생성
collection_name = "hr_policies"

try:
    chroma_client.delete_collection(collection_name)
except:
    pass

collection = chroma_client.create_collection(name=collection_name)

# 문서 임베딩 생성
document_embeddings = [get_embedding(doc) for doc in documents]

# ChromaDB에 문서 저장
collection.add(
    ids=ids,
    documents=documents,
    embeddings=document_embeddings
)

print("문서가 ChromaDB에 저장되었습니다.")
```

---

## 6단계: 사용자 질문 생성

```python
query = "회사 육아휴직 정책 문의"

query_embedding = get_embedding(query)

print("사용자 질문:", query)
print("질문 임베딩 앞 10개 값:")
print(query_embedding[:10])
```

---

## 7단계: 벡터 DB 검색

```python
results = collection.query(
    query_embeddings=[query_embedding],
    n_results=2
)

print("검색 결과:")
print(results["documents"])
```

예상 결과는 다음과 비슷합니다.

```python
[['육아휴직은 최대 1년까지 사용할 수 있습니다.',
  '육아휴직 급여는 고용보험에서 지급됩니다.']]
```

---

## 8단계: 검색된 문서만 추출

```python
retrieved_docs = results["documents"][0]

print("검색된 문서 목록:")
for i, doc in enumerate(retrieved_docs, start=1):
    print(f"{i}. {doc}")
```

---

## 9단계: 프롬프트 구성

```python
context = "\n".join([f"- {doc}" for doc in retrieved_docs])

prompt = f"""
너는 회사 인사 담당자야.
다음 참고 문서를 바탕으로 직원의 질문에 답해.

[직원 질문]
{query}

[참고 문서]
{context}

[답변 작성 규칙]
1. 참고 문서에 있는 내용만 사용해.
2. 문서에 없는 내용은 추측하지 마.
3. 직원이 이해하기 쉽게 친절하게 답변해.
"""

print(prompt)
```

---

## 10단계: LLM으로 최종 답변 생성

```python
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {
            "role": "system",
            "content": "너는 회사 인사 정책을 설명하는 친절한 HR 담당자야."
        },
        {
            "role": "user",
            "content": prompt
        }
    ]
)

answer = response.choices[0].message.content

print("최종 답변:")
print(answer)
```

# 실습에서 확인해야 할 핵심

| 단계       | 확인 내용                   |
| -------- | ----------------------- |
| 임베딩      | 질문과 문서가 숫자 벡터로 변환됨      |
| 벡터 DB 저장 | 문서 chunk가 ChromaDB에 저장됨 |
| 유사도 검색   | 질문과 의미가 가까운 문서가 검색됨     |
| 프롬프트 구성  | 검색된 문서가 LLM 입력에 포함됨     |
| 답변 생성    | LLM이 검색 문서를 근거로 답변함     |

이 실습은 RAG의 핵심 구조 중에서 특히 다음 부분을 직접 확인하는 예제입니다.

```text
Retrieval   → 벡터 DB에서 관련 문서 검색
Augmentation → 검색된 문서를 프롬프트에 삽입
Generation  → LLM이 최종 답변 생성
```
