# 파인튜닝 개요

---

## 1. 파인튜닝(Fine-tuning)이란 정확히 무엇인가?

쉽게 비유하자면, 파인튜닝은 "기본기가 탄탄한 명문대 졸업생에게 우리 회사 전용 업무 매뉴얼을 가르치는 과정"입니다.

* **사전학습 모델 (Pre-trained Model):** 세상의 수많은 데이터(수천 시간의 음성, 수백억 개의 문장)를 미리 공부해서, 언어의 구조나 음성의 특징을 이미 완벽하게 이해하고 있는 상태입니다. (ex: "한국어"라는 언어 자체를 아주 잘 아는 상태)
* **파인튜닝 (Fine-tuning):** 이 똑똑한 모델에게 내가 원하는 특정 목적(AI 비서)과 특정 환경(내 목소리, 내 방 소음, 비서 말투)에 맞는 데이터셋을 추가로 학습시켜, 특정 태스크의 정확도를 극대화하는 기법입니다.

처음부터 모델을 만드는 것(Scratch 학습)은 천문학적인 비용과 데이터가 들지만, 파인튜닝을 이용하면 비교적 적은 데이터와 시간으로도 고성능의 결과물을 낼 수 있습니다.

---

## 2. "나만의 AI 비서" 프로젝트에서 구체적으로 무엇을 파인튜닝할까?

AI 비서 웹 서비스를 만들 때, STT와 TTS 각각의 영역에서 '어떤 데이터'를 가지고 '모델의 어떤 부분'을 수정해야 하는지 구체적으로 가이드해 드릴게요.

### 🎙️ STT (음성 인식: 사용자의 말을 텍스트로)

> **목표:** AI 비서가 내 목소리와 내가 자주 쓰는 명령어를 정확하게 알아듣게 만들기

기존의 범용 STT 모델은 조용한 환경에서 표준어를 구사하는 뉴스 앵커 목소리는 잘 알아듣지만, 내 방 안의 소음이나 내가 자주 쓰는 고유명사(예: 내 친구 이름, 특정 앱 이름)는 잘 못 알아들을 수 있습니다.

* **무엇을 파인튜닝하는가? (데이터 측면)**
* **내 목소리 데이터:** 내가 직접 마이크로 녹음한 음성과 이를 정확히 받아 적은 텍스트 쌍(Audio-Text pairs) 약 수십~수백 개.
* **도메인 특화 데이터:** AI 비서에게 내릴 명령 문장들. (ex: *"자비스, 거실 불 켜줘"*, *"오늘 스케줄 확인해줘"*)


* **어떤 부분을 파인튜닝하는가? (모델 내부 측면)**
* STT 모델의 앞부분(음성의 특징을 추출하는 오디오 인코더)은 그대로 두고, 음성 신호를 텍스트로 변환하는 **출력층(Decoder/Classification Head)** 또는 전체 레이어의 아주 일부(로라, LoRA 같은 경량화 기법 활용)만 학습시킵니다.
* 이를 통해 모델은 '거실 불', '자비스' 같은 특정 단어의 음성 주파수 패턴을 더 민감하게 포착하게 됩니다.



---

### 🗣️ TTS (음성 합성: AI 비서가 목소리로 답변하기)

> **목표:** AI 비서가 딱딱한 기계음이 아니라, 내가 원하는 매력적인 목소리나 특정 말투(친절한 비서 톤)로 말하게 만들기

기존 TTS 모델은 기본 제공되는 무난한 남성/여성 목소리만 낼 수 있습니다. "나만의 비서"라면 독창적인 목소리 톤이 필요하겠죠.

* **무엇을 파인튜닝하는가? (데이터 측면)**
* **타겟 목소리 데이터:** 내가 비서로 만들고 싶은 사람(혹은 본인)의 깨끗하게 녹음된 목소리 파일과 해당 대본 텍스트. (최소 30분~몇 시간 분량 필요)
* **감정 및 말투 데이터:** 비서다운 정중하고 차분한 어조의 문장들.


* **어떤 부분을 파인튜닝하는가? (모델 내부 측면)**
* 텍스트를 음성의 추상적 특징(멜-스펙트로그램)으로 바꾸는 **어텐션(Attention) 메커니즘과 디코더 파트**를 파인튜닝합니다.
* 사전학습 모델이 가진 '글자를 소리로 바꾸는 기본 규칙'은 유지한 채, **소리의 색깔(음색), 억양, 발음 속도**를 타겟 목소리의 스타일로 싹 덮어씌우는(Adaptation) 작업입니다.

## 3. 웹 기반 프로젝트 적용을 위한 아키텍처 요약

실제 웹 서비스로 구현할 때는 파인튜닝된 모델의 '크기'와 '추론 속도'가 핵심입니다.

| 단계 | 웹 프론트엔드 (클라이언트) | 백엔드 / AI 서버 (파인튜닝 모델 탑재) |
| --- | --- | --- |
| **STT** | 사용자가 마이크로 말하면 **오디오 데이터(Web Audio API)**를 서버로 전송 | 파인튜닝된 STT 모델(예: OpenAI Whisper 파인튜닝 버전)이 음성을 실시간 텍스트로 변환 |
| **LLM** | - | 텍스트 명령어(ex: "불 켜줘")를 해석하고 답변 텍스트 생성 |
| **TTS** | 서버에서 받은 오디오 파일이나 스트리밍 데이터를 브라우저에서 재생 | 답변 텍스트를 파인튜닝된 TTS 모델(예: VITS, Glow-TTS 파인튜닝 버전)로 돌려 **내 비서 목소리 오디오**로 변환 |

> 💡 **초보자를 위한 꿀팁 (LoRA 활용하기)**
> 모델 전체를 파인튜닝하는 것은 컴퓨터 사양(GPU VRAM)이 많이 필요합니다.
> 최근에는 **LoRA(Low-Rank Adaptation)**라는 방식을 써서 원래 모델은 얼려두고(Freeze), 아주 작은 크기의 레이어만 추가로 학습시키는 방식을 씁니다.
> 컴퓨터 자원도 아끼고 학습 속도도 엄청나게 빨라지니, 프로젝트 때 꼭 `LoRA 파인튜닝`을 검색해 보세요!
