# AI 음성 모델 만들기 업무 분담표

# 🧩 **5인 팀 업무 분담 구조(LLM 기반 음성 입출력 프로젝트)**

## 🎯 전체 파이프라인 개요  
STT 입력 → LLM 처리 → TTS 출력  
---

# 🗂️ **업무 분담표(5명 기준)**

## 👤 **1. PM·기획 담당**
- 프로젝트 일정 관리, 역할 조율  
- 요구사항 정의서, 기능 명세서 작성  
- 사용자 시나리오 설계  
- 발표자료 구성 총괄  
- 팀 간 커뮤니케이션 중심 역할  
- 산출물: 기획서, 요구사항 명세서, 발표자료 초안

---

## 👤 **2. STT 담당**
- Whisper API 또는 Speech-to-Text 모델 선택  
- 음성 입력 처리 로직 구현  
- 잡음 제거, 입력 길이 제한 등 품질 관리  
- STT 결과를 LLM에 전달하는 인터페이스 개발  
- 산출물: STT 모듈, 음성 입력 테스트 로그

---

## 👤 **3. LLM 프롬프트·로직 담당**
- 시스템 프롬프트 설계  
- 사용자 입력 → LLM → 응답 구조 설계  
- LLM 응답 품질 테스트 및 튜닝  
- 시나리오 기반 테스트 케이스 작성  
- 산출물: 프롬프트 문서, LLM 응답 테스트 로그

---

## 👤 **4. TTS 담당**
- TTS API 선택 및 음성 출력 구현  
- LLM 응답 → 음성 변환 파이프라인 구축  
- 음성 톤, 속도, 자연스러움 테스트  
- 산출물: TTS 모듈, 음성 출력 샘플

---

## 👤 **5. 프론트엔드·UI/UX 담당**
- Streamlit / 웹 UI / 간단한 앱 형태로 인터페이스 제작  
- 음성 입력 버튼, 텍스트 출력창, 음성 재생 UI 구성  
- 전체 파이프라인 통합 테스트  
- 산출물: UI 프로토타입, 최종 데모 화면

---

# 📋 **업무 분담표(표 형태)**

| 역할 | 담당자 | 주요 업무 | 산출물 |
|------|--------|-----------|---------|
| **PM·기획** | 1명 | 일정관리, 요구사항, 발표 | 기획서, 발표자료 |
| **STT 개발** | 1명 | 음성 입력 처리, STT API 연동 | STT 모듈 |
| **LLM 로직** | 1명 | 프롬프트 설계, LLM 응답 품질 개선 | 프롬프트 문서 |
| **TTS 개발** | 1명 | 음성 출력 구현, TTS API 연동 | TTS 모듈 |
| **UI/UX** | 1명 | UI 제작, 전체 통합 | 데모 UI |

---

# 🧱 **팀 간 협업 흐름**
- **STT → LLM → TTS**는 직렬 구조지만  
  **UI/기획은 병렬로 진행 가능**  
- PM은 전체 흐름을 조율하며 병목을 제거  
- LLM 담당은 STT/TTS 담당과 인터페이스 규격을 미리 합의해야 함
