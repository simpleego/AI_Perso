결론부터 말하면 **프롬프트로 어느 정도 줄일 수는 있지만, 100% 해결은 어렵습니다.**
Qwen 계열 모델은 중국어 데이터 비중이 높기 때문에, 페르소나 파인튜닝 후에도 답변 중간에 **한자, 중국어 간체, 번체 문자**가 섞이는 현상이 생길 수 있습니다.

가장 안정적인 해결 방법은 다음 3단계입니다.

---

# 1. 먼저 프롬프트로 제어하기

가벼운 문제라면 프롬프트만으로도 많이 줄어듭니다.

## 추천 System Prompt

```text
당신은 한국어로만 답변하는 AI 상담사입니다.

규칙:
1. 모든 답변은 반드시 현대 한국어 한글로만 작성합니다.
2. 한자, 중국어 간체, 중국어 번체, 일본어 한자 표현을 절대 사용하지 않습니다.
3. 어려운 한자어는 한글로 풀어서 설명합니다.
4. 이름, 기관명, 법률명, 전문용어도 가능한 한 한글 표기를 사용합니다.
5. 답변 생성 중 한자나 중국어 문자가 포함되었다고 판단되면, 즉시 한글 표현으로 바꾸어 다시 작성합니다.
6. 숫자, 영어 약어, 코드, URL은 필요한 경우에만 사용할 수 있습니다.
```

사용자 프롬프트 앞에도 한 번 더 넣으면 좋습니다.

```text
아래 질문에 대해 반드시 한글 한국어로만 답변하세요.
한자나 중국어 문자는 절대 포함하지 마세요.

질문:
{user_question}
```

---

# 2. 생성 옵션을 보수적으로 조정하기

한자가 섞이는 문제가 자주 발생한다면 `temperature`를 낮추는 것이 좋습니다.

```python
generation_config = {
    "max_new_tokens": 512,
    "temperature": 0.2,
    "top_p": 0.8,
    "do_sample": True,
    "repetition_penalty": 1.1
}
```

더 안정적으로 하려면 샘플링을 끄는 방식도 가능합니다.

```python
generation_config = {
    "max_new_tokens": 512,
    "do_sample": False
}
```

`temperature`가 높을수록 모델이 다양한 표현을 시도하면서 중국어/한자가 섞일 가능성이 커질 수 있습니다.

---

# 3. 후처리로 한자 포함 여부 검사하기

실서비스나 데모에서는 프롬프트만 믿지 말고, 답변 후 한자가 포함되었는지 검사하는 것이 좋습니다.

```python
import re

hanja_pattern = re.compile(r"[\u3400-\u4DBF\u4E00-\u9FFF\uF900-\uFAFF]")

def has_hanja_or_chinese(text):
    return bool(hanja_pattern.search(text))


answer = model_answer

if has_hanja_or_chinese(answer):
    print("한자 또는 중국어 문자가 포함되어 있습니다.")
else:
    print("정상 답변입니다.")
```

한자가 포함되면 다시 생성하게 만들 수 있습니다.

```python
def clean_retry_prompt(original_answer):
    return f"""
다음 답변에는 한자 또는 중국어 문자가 포함되어 있습니다.
모든 내용을 자연스러운 한글 한국어로만 다시 작성하세요.
의미는 유지하되, 한자와 중국어 문자는 절대 사용하지 마세요.

원문:
{original_answer}
"""
```

# 4. 가장 근본적인 해결책은 파인튜닝 데이터 정제

프롬프트보다 더 중요한 것은 **파인튜닝 데이터**입니다.

페르소나 파인튜닝 데이터 안에 다음 요소가 있으면 한자가 섞일 수 있습니다.

| 원인                | 설명                                                        |
| ----------------- | --------------------------------------------------------- |
| 중국어/한자 포함 데이터     | 학습 데이터에 `育兒`, `妊娠`, `支援`, `対象` 같은 문자가 있으면 따라 배웁니다.        |
| 번역체 문장            | 한국어처럼 보이지만 중국어식 어순이 섞이면 출력도 흔들립니다.                        |
| 너무 적은 데이터         | 데이터가 적으면 Qwen 기본 모델의 중국어 성향이 다시 나옵니다.                     |
| System Prompt 불일치 | 학습 때와 추론 때 프롬프트 형식이 다르면 응답 스타일이 흔들립니다.                    |
| Chat Template 오류  | Qwen 전용 chat template을 제대로 쓰지 않으면 모델이 이상한 문자를 생성할 수 있습니다. |

---

# 5. 파인튜닝 데이터에 넣으면 좋은 규칙

SFT 데이터의 system 메시지에 다음 내용을 반복적으로 넣는 것이 좋습니다.

```json
{
  "messages": [
    {
      "role": "system",
      "content": "당신은 한국어 전용 AI입니다. 모든 답변은 한글 한국어로만 작성합니다. 한자, 중국어 간체, 중국어 번체는 절대 사용하지 않습니다."
    },
    {
      "role": "user",
      "content": "난임부부 시술비 지원에 대해 알려줘."
    },
    {
      "role": "assistant",
      "content": "난임부부 시술비 지원은 난임 진단을 받은 부부에게 체외수정과 인공수정 시술비 일부를 지원하는 제도입니다. 지원 내용은 시술 종류에 따라 다르며, 자세한 내용은 주소지 보건소에 문의하는 것이 좋습니다."
    }
  ]
}
```

중요한 점은 `assistant` 답변에 한자가 **단 하나도 없어야** 합니다.

# 6. 추천 해결 순서

가장 현실적인 순서는 다음과 같습니다.

```text
1단계: System Prompt에 "한글 한국어만 사용" 규칙 추가
2단계: temperature 낮추기
3단계: 답변 후 한자 포함 여부 정규식 검사
4단계: 한자 포함 시 자동 재생성
5단계: 파인튜닝 데이터에서 한자/중국어 제거
6단계: 필요하면 한글 전용 보정 데이터로 추가 SFT
```

---

# 실습용으로 가장 간단한 방식

현재 바로 적용한다면 이 정도 구성이 좋습니다.

```python
SYSTEM_PROMPT = """
당신은 한국어로만 답변하는 AI입니다.

규칙:
- 모든 답변은 반드시 한글 한국어로만 작성합니다.
- 한자, 중국어 간체, 중국어 번체, 일본어 한자는 절대 사용하지 않습니다.
- 어려운 한자어도 한글로 풀어서 설명합니다.
- 답변 중 한자가 포함될 것 같으면 반드시 한글 표현으로 바꿔 작성합니다.
"""
```

그리고 답변 후 검사합니다.

```python
import re

hanja_pattern = re.compile(r"[\u3400-\u4DBF\u4E00-\u9FFF\uF900-\uFAFF]")

def check_answer(answer):
    if hanja_pattern.search(answer):
        return "한자 또는 중국어 문자가 포함되어 재생성이 필요합니다."
    return "정상 답변입니다."

print(check_answer(answer))
```

---

정리하면, **프롬프트로 어느 정도 해결 가능하지만 안정적인 해결책은 아닙니다.**
강의나 프로젝트 데모 수준이면 **프롬프트 + temperature 조정 + 후처리 검사**로 충분하고, 실제 서비스 수준이면 **파인튜닝 데이터 정제 + 한글 전용 보정 데이터 추가 학습**까지 하는 것이 좋습니다.
