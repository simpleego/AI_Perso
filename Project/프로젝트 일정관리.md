#  **LLM 기반 미니 프로젝트 일정표

> 일정은 **주제 선정 → 데이터 준비 → 모델 활용 → 구현 → 발표** 흐름으로 구성

---

## 📅 2주 LLM 미니 프로젝트 일정표 (비전공자용)

---

## 🗓️ **1일차 ~ 2일차: 주제 선정 & 기획**
- **프로젝트 주제선정** — 해결하고 싶은 문제 정의, 타깃 사용자 설정  
- **요구사항 정의** — 기능 목록, 입력/출력 형태 정리  
- **벤치마킹 조사** — 유사 서비스 탐색, 차별점 도출
- 사전학습 모델 선정 - 프로젝트 수행에 알맞은 모델
- 산출물: 문제정의서, 요구사항 명세서, 간단한 와이어프레임

---

## 🗓️ **3일차 ~ 4일차: 데이터 수집 & 전처리(비전공자용 최소 수준)**
- **데이터 수집** — 음성데이터 수집(녹화), 텍스트 자료, FAQ, 문서 등  
- **데이터 정리** — 음성 잡음제거 및 기타 전처리 작업, 카테고리 분류
- 사전학습 모델 테스트
- **프롬프트 설계** — 모델에게 어떤 방식으로 질문할지 템플릿 작성  
- 산출물: 데이터셋 초안, 프롬프트 템플릿

---

## 🗓️ **5일차 ~ 7일차: LLM 활용 실험**
- **LLM 테스트** — 다양한 프롬프트로 응답 품질 확인  
- **시나리오 기반 테스트** — 실제 사용 상황을 가정한 테스트  
- **응답 개선** — 프롬프트 수정, 시스템 메시지 보완  
- 산출물: 테스트 로그, 개선된 프롬프트, 모델 응답 예시

---

## 🗓️ **8일차 ~ 11일차: 구현(간단한 UI 또는 챗봇 형태)**
- **UI 설계** — draw.io/Streamlit/HTML 등 쉬운 도구 활용  
- **기능 구현** — 입력창, 출력창, 버튼 정도의 최소 기능  
- **통합 테스트** — 실제 사용 흐름 점검  
- 산출물: 초기 버전 데모, 기능 설명서

---

## 🗓️ **12일차 ~ 13일차: 결과 정리 & 발표 준비**
- **결과 분석** — 잘된 점/한계/개선점  
- **발표자료 제작** — 문제 → 해결방법 → 데모 → 배운 점  
- **데모 시연 준비**  
- 산출물: 발표 PPT, 데모 영상 또는 실시간 시연 준비

---

## 🗓️ **14일차: 최종 발표**
- **최종 발표** — 팀별 발표 및 피드백  
- 산출물: 프로젝트 결과보고서, 결과물(소스코드, 데이터), 발표자료, 회고록

---

# 📘 프로젝트 수행 중 반드시 작성해야 하는 기본 문서
아래는 비전공자도 쉽게 작성할 수 있는 필수 문서 목록

- **문제정의서** — 해결하고 싶은 문제, 대상, 기대효과  
- **요구사항 명세서** — 기능 목록, 입력/출력  
- **데이터 정리 문서** — 데이터 출처, 구조, 전처리 방식  
- **프롬프트 설계 문서** — 시스템/사용자/예시 프롬프트  
- **테스트 로그** — 어떤 입력에 어떤 응답이 나왔는지 기록  
- **발표자료** — 프로젝트 전체 흐름 정리  
- **회고록** — 배운 점, 아쉬운 점, 다음 개선 방향
