## 4. 순차 처리 파이프라인 (Sequence Diagram)

```mermaid
sequenceDiagram
    participant User as 사용자
    participant WA as Wake Word<br/>Detector
    participant VAD as VAD
    participant ASR as ASR
    participant NLU as NLU
    
    User->>WA: 음성/텍스트 입력
    WA->>WA: wake word 감지
    
    alt wake word 발견됨
        WA->>User: wake word 확인
        User->>VAD: 실제 명령어
        VAD->>VAD: 음성 구간 탐지
        VAD->>ASR: 음성 구간 전달
        ASR->>ASR: 음성→텍스트 변환
        ASR->>NLU: 텍스트 전달
        NLU->>NLU: 의도/엔티티 추출
        NLU->>User: 최종 응답
    else wake word 없음
        WA->>User: 무시 (대기 상태)
    end
```

## 함수 기반 vs 클래스 기반 비교

| 관점 | 클래스 기반 | 함수 기반 |
|------|------------|----------|
| **적합한 다이어그램** | 클래스 다이어그램 | 흐름도, 데이터 흐름도, 시퀀스 다이어그램 |
| **구조 표현** | 계층적 구조 | 처리 흐름 중심 |
| **재사용성 표현** | 상속/포함 관계 | 함수 호출 관계 |
| **상태 표현** | 멤버 변수 | 파라미터/반환값 |

함수 기반 코드에서는 **어떤 데이터가 어떤 함수를 거쳐 어떻게 변환되는지**를 보여주는 다이어그램이 더 의미 있습니다.
