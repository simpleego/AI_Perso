# 음성 기반 PERSO AI 구현

---

### 🎯 프로젝트 핵심 컨셉: "Voice PERSO AI"
*   **PERSO(Persona):** 프롬프트와 파인튜닝을 통해 고유한 성격, 말투, 지식관을 가진 AI
*   **Voice:** 텍스트를 넘어, 페르소나에 맞는 목소리(STT/TTS)로 대화하는 인터페이스
*   **핵심 기술 스택:** OpenAI/Clova API(또는 직접 파인튜닝한 모델), Whisper(STT), TTS API, Streamlit(또는 Gradio)

---

### 🗓️ 1주차: PERSO의 뇌 만들기 (텍스트 기반 페르소나 구축)
**목표:** 랭체인 없이 직접 API를 호출하며, 프롬프트와 파인튜닝을 통해 완벽한 텍스트 페르소나를 완성하고 대화 맥락(Memory)을 관리한다.

| 일자 | 주제 | 주요 학습 및 구현 내용 | 실습 과제 |
| :-- | :-- | :-- | :-- |
| **1일** | **API 직접 제어 및 아키텍처** | - 랭체인 없이 `requests` 라이브러리로 LLM API 직접 호출<br>- Chat API의 `messages` 배열 구조 이해 (Role별 데이터 관리)<br>- 스트리밍(Streaming) 응답 처리 | - Python으로 API 직접 호출하여 답변 받기<br>- 응답을 한 글자씩 터지듯 출력하는 스트리밍 구현 |
| **2일** | **프롬프트로 페르소나 각인시키기** | - System Prompt를 활용한 페르소나 정의 (성격, 말투, 금칙어)<br>- Few-shot prompting으로 특정 말투 학습<br>- 페르소나 이탈 방지 프롬프트 작성 | - "20대 힙한 카페 사장님" 또는 "까칠한 but 따뜻한 고양이" 프롬프트 작성 및 테스트 |
| **3일** | **파인튜닝을 통한 페르소나 고도화** | - 파인튜닝용 데이터셋(JSONL) 포맷 및 전처리<br>- 선행 학습 지식을 활용한 경량 파인튜닝(API 기반)<br>- 프롬프트만 쓴 모델 vs 파인튜닝 모델 비교 | - 특정 캐릭터의 말투 데이터 50~100개 수집 및 전처리<br>- API를 활용한 간단한 파인튜닝 실행 및 결과 테스트 |
| **4일** | **대화 맥락(Memory) 직접 관리** | - RAG 없이 토큰 제한(Context Window) 내 대화 기록 유지<br>- Sliding Window (최근 N개 대화만 유지) 로직 구현<br>- 오래된 대화 요약(Summarization)하여 맥락 잇기 | - 대화가 20턴이 넘어가도 이전 내용을 기억하는 로직 구현<br>- 토큰 초과 시 에러가 나지 않도록 메시지 배열 슬라이싱 |
| **5일** | **텍스트 UI 및 페르소나 평가** | - Streamlit을 활용한 텍스트 채팅 UI 구현<br>- 사이드바에서 페르소나(프롬프트/파인튜닝 모델) 선택 기능<br>- 페르소나 일관성 평가 및 프롬프트 최종 수정 | - 텍스트 기반 챗봇 UI 완성<br>- 1주차 결과물: 페르소나별 텍스트 챗봇 데모 |

### 🗓️ 2주차: PERSO에 몸과 목소리 입히기 (음성 모델 통합)
**목표:** 선행 학습한 음성 모델(STT/TTS) 지식을 활용하여, 텍스트 페르소나에 맞는 '목소리'와 '대화 인터페이스'를 결합한다.

| 일자 | 주제 | 주요 학습 및 구현 내용 | 실습 과제 |
| :-- | :-- | :-- | :-- |
| **6일** | **STT (음성인식) 파이프라인** | - 마이크 입력 오디오 캡처 (WebRTC 또는 파일 업로드)<br>- Whisper API(또는 로컬 모델)를 통한 음성->텍스트 변환<br>- 잡음 처리 및 문장 끝맺음(End-point) 감지 기초 | - 브라우저에서 음성 녹음하여 텍스트로 변환하기<br>- 변환된 텍스트를 LLM에 전달하는 파이프라인 연결 |
| **7일** | **TTS (음성합성) 및 보이스 페르소나** | - LLM 답변을 음성으로 변환 (TTS API 호출)<br>- **페르소나에 맞는 보이스 매칭** (예: 할아버지 캐릭터 -> 낮은 톤, 느린 속도)<br>- 음성 속도(Pitch/Rate) 및 감정 조절 | - "까칠한 고양이"에는 빠르고 높은 목소리,<br>"따뜻한 상담사"에는 차분한 목소리 적용해보기 |
| **8일** | **End-to-End 음성 대화 루프** | - STT ➡️ LLM ➡️ TTS 전체 파이프라인 직렬 연결<br>- **지연시간(Latency) 최소화** (LLM 스트리밍을 TTS와 병렬 처리하는 기초 개념)<br>- 오디오 파일 자동 재생 및 UI 연동 | - 말하고 -> AI가 생각해서 -> 목소리로 대답하는<br>완전한 음성 대화 루프 구현 |
| **9일** | **UI/UX 고도화 및 예외 처리** | - 음성 시각화 (파형 애니메이션 등 간단한 CSS/JS)<br>- API 타임아웃, STT 인식 실패 시 fallback(대응) 로직<br>- 대화 중 끊기(Interruption) 또는 중복 입력 방지 | - AI가 대답하는 중에는 마이크 입력 차단하는 로직 추가<br>- UI에 "생각 중...", "말씀하세요..." 등 상태 표시 |
| **10일** | **최종 프로젝트 및 데모** | - 전체 시스템 통합 테스트<br>- 페르소나별 보이스 및 말투 시연<br>- 프로젝트 발표 및 피드백 | - **최종 결과물: 나만의 보이스 PERSO AI**<br>(예: 보이스 튜링 테스트, 가상 아이돌, 보이스 멘토 등) |

### 💡 조건에 맞춘 핵심 설계 포인트 (Why this works?)

#### 1. 랭체인/RAG를 뺀 대신 'Context 관리'와 '파인튜닝'에 집중
*   랭체인이 없으므로 `messages` 배열을 Python 리스트로 직접 관리하며 **토큰 제한을 초과하지 않도록 슬라이싱(Slicing)하거나 요약**하는 로직을 직접 짭니다. 이를 통해 LLM의 내부 구조(Context Window)를 비전공자도 직관적으로 이해하게 됩니다.
*   외부 지식(RAG) 대신, **파인튜닝을 통해 모델의 가중치 자체에 페르소나의 말투와 지식을 주입**합니다. "데이터셋을 어떻게 만들면 AI가 특정 말투를 배우는가"를 체득하게 됩니다.

#### 2. '텍스트 페르소나'와 '보이스 페르소나'의 일치 (Voice Persona)
*   단순히 TTS를 붙이는 것이 아니라, **프롬프트/파인튜닝으로 만든 성격과 TTS의 목소리 톤을 맞추는 것**이 2주차의 핵심입니다.
*   *예시:* 텍스트 프롬프트로 "느리고 존댓말을 쓰는 노인"을 만들었다면, TTS API 호출 시 `speed=0.8`, `pitch=low` 등의 파라미터를 매칭해야 몰입감이 생깁니다.

#### 3. 지연시간(Latency) 체감 최소화
*   음성 AI의 가장 큰 적은 '침묵(대기 시간)'입니다. LLM이 텍스트를 다 생성할 때까지 기다렸다가 TTS를 호출하면 답답합니다.
*   2주차 8일 차에는 **LLM이 문장 단위로 스트리밍 출력할 때, 완성된 문장부터 먼저 TTS로 보내는 파이프라인**을 구현하도록 유도하여 체감 속도를 높이는 엔지니어링을 경험하게 합니다.

### 🚀 최종 프로젝트 예시 (Voice PERSO AI)

1.  **보이스 멘탈 코치 (PERSO: Warm Mentor)**
    *   **특징:** 사용자의 고민을 음성으로 들으면, 공감하는 말투와 차분한 목소리로 상담.
    *   **구현:** 파인튜닝으로 공감어린 말투 학습 + 낮은 톤의 차분한 TTS 보이스 매칭.
2.  **영어 회화 파트너 (PERSO: Energetic Tutor)**
    *   **특징:** 사용자의 영어 발음(STT)을 듣고, 틀린 부분을 교정하며 밝은 목소리로 대화.
    *   **구현:** STT로 사용자 음성 인식 + LLM이 교정 프롬프트 수행 + 밝고 빠른 TTS 보이스.
3.  **가상 아이돌 / 캐릭터 보이스챗 (PERSO: K-pop Idol)**
    *   **특징:** 특정 아이돌의 말투와 팬 서비스를 음성으로 제공.
    *   **구현:** 해당 아이돌의 말투 데이터로 파인튜닝 + 아이돌 보이스 클론(또는 유사 보이스) TTS 적용.
4.  **시각장애인용 보이스 도우미 (PERSO: Clear Guide)**
    *   **특징:** 복잡한 텍스트 정보(날씨, 뉴스)를 음성으로 명확하고 간결하게 요약하여 전달.
    *   **구현:** 정보 요약 프롬프트 + 명확하고 또렷한 아나운서 스타일의 TTS.
