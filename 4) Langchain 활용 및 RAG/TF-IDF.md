# TF-IDF
> TF-IDF는 **문서에서 중요한 단어를 찾는 방법**입니다.

쉽게 말하면 다음 두 가지를 함께 봅니다.

> **어떤 문서 안에서는 자주 나오지만, 전체 문서들에서는 흔하지 않은 단어가 중요하다.**

---

## 1. TF-IDF의 기본 생각

예를 들어 문서가 3개 있다고 해보겠습니다.

| 문서   | 내용                  |
| ---- | ------------------- |
| 문서 1 | 사과는 맛있다. 사과는 빨갛다.   |
| 문서 2 | 바나나는 맛있다. 바나나는 노랗다. |
| 문서 3 | 사과와 바나나는 과일이다.      |

여기서 단어를 보면 다음과 같습니다.

| 단어  | 특징                        |
| --- | ------------------------- |
| 맛있다 | 여러 문서에 나옴                 |
| 사과  | 문서 1에서 자주 나오고, 일부 문서에만 나옴 |
| 바나나 | 문서 2에서 자주 나오고, 일부 문서에만 나옴 |
| 과일  | 문서 3에서만 나옴                |

TF-IDF는 이런 식으로 판단합니다.

---

## 2. TF란?

**TF**는 **Term Frequency**, 즉 **단어 빈도**입니다.

> 특정 문서 안에서 어떤 단어가 얼마나 자주 나오는가?

예를 들어 문서 1을 봅시다.

> 문서 1: 사과는 맛있다. 사과는 빨갛다.

문서 1에서 단어 빈도는 대략 다음과 같습니다.

| 단어  | 등장 횟수 |
| --- | ----: |
| 사과  |    2번 |
| 맛있다 |    1번 |
| 빨갛다 |    1번 |

여기서는 **사과**가 많이 나왔으므로 TF 값이 높습니다.

즉, TF 관점에서는 **문서 1은 사과에 관한 문서일 가능성이 높다**고 볼 수 있습니다.

---

## 3. IDF란?

**IDF**는 **Inverse Document Frequency**, 즉 **역문서 빈도**입니다.

> 전체 문서들 중에서 그 단어가 얼마나 희귀한가?

예를 들어 단어가 여러 문서에 공통으로 많이 등장하면 중요도가 낮아집니다.

| 단어  |    등장 문서 수 | 해석         |
| --- | ---------: | ---------- |
| 맛있다 | 문서 1, 문서 2 | 비교적 흔한 단어  |
| 사과  | 문서 1, 문서 3 | 특정 주제성이 있음 |
| 바나나 | 문서 2, 문서 3 | 특정 주제성이 있음 |
| 빨갛다 |       문서 1 | 희귀함        |
| 노랗다 |       문서 2 | 희귀함        |
| 과일  |       문서 3 | 희귀함        |

IDF는 **모든 문서에 자주 나오는 단어는 덜 중요하다**고 봅니다.

예를 들어 “이다”, “은”, “는”, “그리고”, “좋다” 같은 단어는 여러 문서에 자주 나오기 때문에 주제를 구분하는 힘이 약합니다.

반면 “사과”, “바나나”, “딥러닝”, “RAG”, “반도체” 같은 단어는 특정 문서의 주제를 더 잘 나타낼 수 있습니다.

---

## 4. TF-IDF는 둘을 곱한 값

TF-IDF는 다음처럼 계산합니다.

```text
TF-IDF = TF × IDF
```

즉,

```text
문서 안에서 자주 나오고 × 전체 문서에서는 흔하지 않으면 = 중요한 단어
```

입니다.

---

## 5. 직관적인 예시

문서 1이 다음과 같다고 해보겠습니다.

> 문서 1: 사과는 맛있다. 사과는 빨갛다. 사과는 과일이다.

여기서 단어별 느낌은 이렇습니다.

| 단어  | 문서 1 안에서 자주 나오는가? | 전체 문서에서 흔한가? | TF-IDF 중요도 |
| --- | ----------------- | ------------ | ---------- |
| 사과  | 높음                | 보통           | 높음         |
| 맛있다 | 보통                | 흔함           | 낮음         |
| 과일  | 보통                | 보통           | 중간         |
| 빨갛다 | 보통                | 희귀함          | 중간~높음      |

결국 문서 1의 핵심 단어는 **사과**, **빨갛다**, **과일** 쪽으로 잡힐 가능성이 높습니다.

---

## 6. 왜 단순 빈도만 보면 안 될까?

단순히 많이 나온 단어만 보면 문제가 생깁니다.

예를 들어 여러 뉴스 문서가 있다고 해보겠습니다.

| 문서   | 내용                |
| ---- | ----------------- |
| 문서 1 | 인공지능 기술이 발전하고 있다. |
| 문서 2 | 반도체 기술이 발전하고 있다.  |
| 문서 3 | 바이오 기술이 발전하고 있다.  |

여기서 **기술**, **발전**, **있다** 같은 단어는 여러 문서에 공통으로 나옵니다.

하지만 이 단어들은 문서를 구분하는 데 큰 도움이 되지 않습니다.

오히려 중요한 단어는 다음과 같습니다.

| 문서   | 중요한 단어 |
| ---- | ------ |
| 문서 1 | 인공지능   |
| 문서 2 | 반도체    |
| 문서 3 | 바이오    |

TF-IDF는 이런 공통 단어의 중요도는 낮추고, 문서별 특징을 잘 보여주는 단어의 중요도는 높입니다.

---

## 7. 검색 시스템에서의 TF-IDF 예시

사용자가 검색창에 이렇게 입력했다고 해보겠습니다.

```text
인공지능 교육
```

문서가 다음과 같이 있습니다.

| 문서   | 내용                  |
| ---- | ------------------- |
| 문서 A | 인공지능 교육 과정과 머신러닝 실습 |
| 문서 B | 초등학교 교육 과정 개편       |
| 문서 C | 인공지능 모델 개발과 딥러닝     |

검색어는 **인공지능 교육**입니다.

TF-IDF 관점에서 보면:

| 문서   | 판단                             |
| ---- | ------------------------------ |
| 문서 A | “인공지능”, “교육” 둘 다 포함 → 가장 관련 높음 |
| 문서 B | “교육”은 있지만 “인공지능” 없음 → 관련 중간    |
| 문서 C | “인공지능”은 있지만 “교육” 없음 → 관련 중간    |

따라서 검색 결과는 보통 다음 순서가 됩니다.

```text
1위: 문서 A
2위: 문서 C 또는 문서 B
```

이런 방식으로 TF-IDF는 **검색엔진, 문서 분류, 키워드 추출, 추천 시스템** 등에 사용됩니다.

---

## 8. 한 줄 요약

**TF-IDF는 어떤 문서에서 자주 나오지만, 전체 문서에서는 흔하지 않은 단어를 중요한 단어로 판단하는 방법입니다.**

즉,

```text
TF  = 이 문서에서 많이 나오는 단어인가?
IDF = 전체 문서에서는 드문 단어인가?
TF-IDF = 이 문서를 대표할 만한 중요한 단어인가?
```
