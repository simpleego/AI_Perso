제시한 코드는 최신 LangChain API 기준으로 다음 부분을 수정해야 합니다.

* `sav\ne_purchase` 오타를 `save_purchase`로 수정
* `runtime.context.get(...)` 대신 **Context 데이터 클래스**와 `runtime.context.user_id` 사용
* `store.get()` 결과는 딕셔너리가 아니라 `StoreValue`이므로 `existing["value"]` 대신 `existing.value` 사용
* namespace는 리스트보다 튜플 `("users", user_id)` 사용
* `user_id`는 `config`에 직접 넣지 않고 `context=ShoppingContext(...)`로 전달
* `MemorySaver`보다 현재 문서에서 사용하는 이름인 `InMemorySaver` 사용

LangChain의 Store는 장기 메모리이고, Checkpointer는 `thread_id`별 대화 기록을 보존하는 단기 메모리입니다. ([Docs by LangChain][1])

# 3. Colab 실행용 전체 코드

아래 코드는 셀 하나에서 실행할 수 있도록 수정한 완성본입니다.

```python
from __future__ import annotations

from dataclasses import dataclass
from datetime import datetime
from typing import Any

from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.tools import tool, ToolRuntime
from langgraph.checkpoint.memory import InMemorySaver
from langgraph.store.memory import InMemoryStore


# =========================================================
# 1. 런타임 Context 정의
# =========================================================

@dataclass
class ShoppingContext:
    """도구 실행 시 전달할 사용자 정보."""

    user_id: str


# =========================================================
# 2. 구매 이력 저장 도구
# =========================================================

@tool
def save_purchase(
    product_name: str,
    category: str,
    runtime: ToolRuntime[ShoppingContext],
) -> str:
    """
    사용자가 구매한 상품과 카테고리를 구매 이력에 저장합니다.

    Args:
        product_name: 구매한 상품명
        category: 상품 카테고리
    """

    # create_agent에 전달한 Store
    store = runtime.store

    if store is None:
        return "구매 이력을 저장할 Store가 설정되지 않았습니다."

    # invoke 시 전달한 사용자 Context
    user_id = runtime.context.user_id

    # 사용자별 저장 공간
    namespace = ("users", user_id)
    key = "purchase-history"

    # 기존 구매 이력 조회
    existing = store.get(namespace, key)

    # StoreValue 객체의 실제 데이터는 .value로 접근
    if existing is None:
        history: list[dict[str, Any]] = []
    else:
        history = list(existing.value)

    # 새 구매 내역 추가
    history.append(
        {
            "product": product_name,
            "category": category,
            "date": datetime.now().isoformat(
                timespec="seconds"
            ),
        }
    )

    # 최근 구매 이력 100개만 유지
    updated_history = history[-100:]

    # 장기 메모리에 저장
    store.put(
        namespace,
        key,
        updated_history,
    )

    return (
        f"{product_name} 상품을 "
        f"{category} 카테고리 구매 이력에 저장했습니다."
    )


# =========================================================
# 3. 추천 상품 조회 도구
# =========================================================

@tool
def get_recommendations(
    runtime: ToolRuntime[ShoppingContext],
) -> str:
    """
    사용자의 구매 이력을 분석하여
    가장 많이 구매한 카테고리의 상품을 추천합니다.
    """

    store = runtime.store

    if store is None:
        return "구매 이력을 조회할 Store가 설정되지 않았습니다."

    user_id = runtime.context.user_id

    namespace = ("users", user_id)
    key = "purchase-history"

    # 구매 이력 조회
    memory = store.get(namespace, key)

    if memory is None:
        return "아직 저장된 구매 이력이 없습니다."

    # StoreValue 객체에서 실제 값 추출
    history = memory.value

    if not history:
        return "아직 저장된 구매 이력이 없습니다."

    # 카테고리별 구매 횟수 계산
    category_counts: dict[str, int] = {}

    for item in history:
        category = item.get("category", "기타")

        category_counts[category] = (
            category_counts.get(category, 0) + 1
        )

    # 가장 많이 구매한 카테고리
    top_category = max(
        category_counts,
        key=category_counts.get,
    )

    purchase_count = category_counts[top_category]

    return (
        f"이전에 {top_category} 카테고리 상품을 "
        f"{purchase_count}번 구매하셨습니다. "
        f"{top_category} 카테고리의 신상품이나 "
        f"인기 상품을 추천드립니다."
    )


# =========================================================
# 4. 구매 이력 전체 조회 도구
# =========================================================

@tool
def get_purchase_history(
    runtime: ToolRuntime[ShoppingContext],
) -> str:
    """
    사용자의 전체 구매 이력을 최근 구매순으로 조회합니다.
    """

    store = runtime.store

    if store is None:
        return "구매 이력을 조회할 Store가 설정되지 않았습니다."

    user_id = runtime.context.user_id

    namespace = ("users", user_id)
    key = "purchase-history"

    memory = store.get(namespace, key)

    if memory is None or not memory.value:
        return "아직 저장된 구매 이력이 없습니다."

    history = memory.value

    lines = ["구매 이력입니다."]

    # 최근 구매가 먼저 출력되도록 역순 처리
    for number, item in enumerate(
        reversed(history),
        start=1,
    ):
        lines.append(
            f"{number}. {item['product']} "
            f"({item['category']}, {item['date']})"
        )

    return "\n".join(lines)


# =========================================================
# 5. 모델과 메모리 생성
# =========================================================

model = init_chat_model(
    "openai:gpt-4o",
    temperature=0,
)

tools = [
    save_purchase,
    get_recommendations,
    get_purchase_history,
]

# 장기 메모리
# 사용자별 구매 이력을 저장
store = InMemoryStore()

# 단기 메모리
# thread_id별 대화 내용을 저장
checkpointer = InMemorySaver()


# =========================================================
# 6. 에이전트 생성
# =========================================================

agent = create_agent(
    model=model,
    tools=tools,
    checkpointer=checkpointer,
    store=store,
    context_schema=ShoppingContext,
    system_prompt="""
당신은 사용자의 구매 이력을 관리하고 상품을 추천하는
쇼핑 도우미입니다.

사용자가 상품을 구매했다고 말하면 반드시 save_purchase 도구를
사용하여 상품명과 카테고리를 저장하세요.

사용자가 추천을 요청하면 반드시 get_recommendations 도구를
사용하여 구매 이력을 분석하세요.

사용자가 구매 이력을 요청하면 반드시 get_purchase_history 도구를
사용하세요.

도구 실행 결과를 바탕으로 한국어로 간단하고 정확하게 답변하세요.
""",
)


# =========================================================
# 7. 사용자와 대화 설정
# =========================================================

# thread_id는 대화 세션을 구분
config = {
    "configurable": {
        "thread_id": "shopping-1",
    }
}

# user_id는 사용자 Context로 별도 전달
context = ShoppingContext(
    user_id="user-789"
)


# =========================================================
# 8. 대화 실행 함수
# =========================================================

def run_agent(user_message: str) -> str:
    """사용자 메시지를 에이전트에 전달하고 최종 답변을 반환합니다."""

    result = agent.invoke(
        {
            "messages": [
                {
                    "role": "user",
                    "content": user_message,
                }
            ]
        },
        config=config,
        context=context,
    )

    final_message = result["messages"][-1]

    return final_message.content


# =========================================================
# 9. 대화 테스트
# =========================================================

print("[대화 1]")
response1 = run_agent(
    "노트북을 구매했어요. 카테고리는 전자제품입니다."
)
print(response1)


print("\n[대화 2]")
response2 = run_agent(
    "마우스도 구매했습니다. 전자제품 카테고리입니다."
)
print(response2)


print("\n[대화 3]")
response3 = run_agent(
    "제 구매 이력을 바탕으로 상품을 추천해 주세요."
)
print(response3)


print("\n[대화 4]")
response4 = run_agent(
    "지금까지의 구매 이력을 보여 주세요."
)
print(response4)
```

# 5. 원래 코드의 주요 오류

## 오류 1. 함수명 줄바꿈

원래 코드:

```python
@tool
def sav

e_purchase(
```

수정:

```python
@tool
def save_purchase(
```

이 부분은 Python 문법 오류를 발생시킵니다.

---

## 오류 2. `runtime.context`를 딕셔너리처럼 접근

원래 코드:

```python
user_id = runtime.context.get("user_id", "default")
```

최신 방식에서는 Context 스키마를 정의하고 객체 속성으로 접근하는 것이 명확합니다.

```python
@dataclass
class ShoppingContext:
    user_id: str
```

```python
user_id = runtime.context.user_id
```

그리고 에이전트 생성 시 스키마를 등록합니다.

```python
agent = create_agent(
    model=model,
    tools=tools,
    context_schema=ShoppingContext,
)
```

호출할 때는 `context` 인수로 전달합니다.

```python
agent.invoke(
    {"messages": [...]},
    config=config,
    context=ShoppingContext(user_id="user-789"),
)
```

공식 문서에서도 런타임 Context는 `context_schema`로 구조를 지정하고, `invoke(..., context=...)`로 전달합니다. ([Docs by LangChain][2])

---

## 오류 3. Store 결과를 딕셔너리처럼 접근

원래 코드:

```python
existing = store.get(namespace, key)
history = existing["value"] if existing else []
```

`store.get()`은 `StoreValue` 객체를 반환합니다. 실제 저장값은 `.value`로 가져옵니다. ([Docs by LangChain][1])

수정:

```python
existing = store.get(namespace, key)
history = list(existing.value) if existing else []
```

추천 도구도 동일하게 수정합니다.

```python
memory = store.get(namespace, key)
history = memory.value
```

---

## 오류 4. `user_id` 전달 위치

원래 코드:

```python
config = {
    "configurable": {"thread_id": "shopping-1"},
    "user_id": "user-789"
}
```

이 구조에서는 `user_id`가 `runtime.context`로 자동 전달되지 않습니다.

수정된 구분은 다음과 같습니다.

```python
config = {
    "configurable": {
        "thread_id": "shopping-1"
    }
}
```

```python
context = ShoppingContext(
    user_id="user-789"
)
```

```python
agent.invoke(
    {"messages": [...]},
    config=config,
    context=context,
)
```

* `thread_id`: 대화 세션 식별
* `user_id`: 실제 사용자 식별
* `config`: 그래프 실행 및 Checkpointer 설정
* `context`: 도구에 주입할 사용자·환경 정보

# 6. Store와 Checkpointer의 차이

| 구성요소         | 현재 코드             | 역할                      |
| ------------ | ----------------- | ----------------------- |
| Store        | `InMemoryStore()` | 사용자별 구매 이력 저장           |
| Checkpointer | `InMemorySaver()` | `thread_id`별 대화 내용 저장   |
| Context      | `ShoppingContext` | 현재 실행 사용자의 `user_id` 전달 |
| State        | `messages`        | 현재 대화 메시지 관리            |

Store는 대화 스레드와 독립적으로 장기 정보를 저장하며, Checkpointer는 특정 `thread_id`의 대화 상태를 저장합니다. ([Docs by LangChain][3])

# 7. 서로 다른 대화에서 구매 이력 확인

장기 메모리는 `thread_id`가 달라져도 동일한 `user_id`라면 조회할 수 있습니다.

```python
new_config = {
    "configurable": {
        "thread_id": "shopping-2",
    }
}

result = agent.invoke(
    {
        "messages": [
            {
                "role": "user",
                "content": "이전 구매 이력을 기반으로 추천해 주세요.",
            }
        ]
    },
    config=new_config,
    context=ShoppingContext(
        user_id="user-789"
    ),
)

print(result["messages"][-1].content)
```

`thread_id`가 `shopping-1`에서 `shopping-2`로 바뀌었지만, Store namespace가 같은 사용자 ID를 사용하므로 이전 구매 이력을 조회할 수 있습니다.

```python
namespace = ("users", "user-789")
```

# 9. 실습 시 주의점

`InMemoryStore`와 `InMemorySaver`는 모두 Colab 메모리에만 데이터를 저장합니다.

따라서 다음 상황에서는 구매 이력과 대화 기록이 삭제됩니다.

```text
런타임 재시작
세션 종료
런타임 연결 해제
```

운영 환경에서는 다음처럼 교체해야 합니다.

```python
from langgraph.store.postgres import PostgresStore
from langgraph.checkpoint.postgres import PostgresSaver
```

* `PostgresStore`: 구매 이력 같은 장기 메모리 저장
* `PostgresSaver`: 대화 스레드와 실행 상태 저장

`InMemorySaver`는 테스트와 디버깅용이며, 운영 환경에서는 PostgreSQL 기반 저장소가 권장됩니다. ([reference.langchain.com][4])
