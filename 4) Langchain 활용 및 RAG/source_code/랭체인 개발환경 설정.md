## 2. 패키지 설치

```cmd
pip install langchain langchain-openai
```
> 랭체인 패키지(langchain)와 랭체인에서 사용할 LLM 모델인 openai의 GPT를 사용하기 위해서 "langchain-openai"패키지를 설치한다.
> 추가적으로 필요한 LLM 모델에 따라서 아래와 같이 추가적으로 설치하면 된다.
> 

```cmd
Anthropic (Claude): pip install langchain-anthropic
Google (Gemini): pip install langchain-google-genai

아래와 같이 필요한 모든 패키지를 한번에 설치하는 방법도 있다.

pip install langchain langchain-openai langchain-anthropic langgraph
```

그리고 추가적인 pip 명령어는 아래 링크를 참조한다.
[pip 명령어 요약 문서 보기](https://github.com/simpleego/AI_Perso/blob/main/pip_summary.md)

> 설치된 패키지 이름 및 버전을 확인한다.
> 패키지 설치시 의존성(패키지 개발시 사용된 모듈참조)을 체크하여 추가적인 패키지를 자동으로 설치한다.
> 따라서 패키지 설치시 이미 설치된 패키지와 버전의 차이 등이 발생할 수 있고, 패키지가 중복되어 출동이 발생할 수 있음을 알고 있어야 한다.
>
