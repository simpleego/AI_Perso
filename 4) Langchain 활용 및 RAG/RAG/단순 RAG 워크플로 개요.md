# 단순 RAG 워크플로 개요

## RAG란?
RAG(Retrieval-Augmented Generation)는 외부 콘텐츠를 모델에 컨텍스트로 제공하여 모델이 더욱 정확하고 유익한 답변을 할 수 있도록 하는 기술입니다.   
LLM을 개념에 대한 일반적인 이해와 학습되지 않은 새로운 정보 또는 독점 정보에 대한 제한적인 지식을 가진 기본 "두뇌"라고 생각하시면 됩니다.   
RAG를 사용하면 모델에 관련성이 부족한 정보를 제공하여 모델이 이러한 추가 컨텍스트를 활용하여 쿼리에 더욱 효과적으로 답변할 수 있도록 합니다.
