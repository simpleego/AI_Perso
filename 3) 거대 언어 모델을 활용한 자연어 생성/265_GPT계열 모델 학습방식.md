# GPT 학습 방식: 다음 단어 예측
> **Autoregressive Next Word Prediction — 자기회귀 다음 단어 예측**

---

## 1. 개념 설명

> **핵심 아이디어:** GPT는 "이전 단어들을 보고 다음 단어를 예측"하는 방식으로 학습합니다.
> 예: `"나는 어제 친구와 ___"` → `"영화를"`

---

### 학습 원리 — 자기회귀 (Autoregressive)

| STEP | 단계 | 설명 |
|------|------|------|
| 01 | 📝 입력 구성 | 문장을 토큰으로 분리 `"나는 어제 친구와 영화를 봤다"` → `[나는, 어제, 친구와, ...]` |
| 02 | 🔮 다음 단어 예측 | `"나는 어제 친구와"` 를 보고 `"영화를"` 을 예측 → Causal Masking 적용 |
| 03 | 📉 손실 계산 & 역전파 | Cross-Entropy Loss 계산 → 오차를 역방향으로 전파 → 파라미터 업데이트 |

---

### 핵심 수식


$$
P(w_t \mid w_1, w_2, \ldots, w_{t-1})
$$

- **의미:** t번째 단어의 확률은 이전 모든 단어에 의존합니다.
- **목표:** 정답 단어의 확률을 최대화 (= Loss 최소화)

---

### GPT 구조의 핵심 — Causal Masking

GPT는 **Decoder-only** 구조입니다. 학습할 때 미래의 단어를 미리 보면 안 되기 때문에, 현재 위치 이후의 토큰을 가리는 **Causal(인과적) Masking**을 적용합니다.

```
나는(✓) → 어제(✓) → 친구와(✓) → [영화를 봤다 — 가려짐 🔒]
```

---

### GPT 파라미터 발전 역사

| 모델 | 연도 | 파라미터 수 |
|------|------|------------|
| GPT-1 | 2018 | 1.17억 |
| GPT-2 | 2019 | 15억 |
| GPT-3 | 2020 | 1,750억 |
| GPT-4 | 2023 | 수천억+ (비공개) |

## 2. PyTorch 구현 코드

### ① 토크나이저 & 데이터셋

```python
import torch
import torch.nn as nn
from torch.utils.data import Dataset, DataLoader

# 간단한 예시 문장
sentences = [
    "나는 어제 친구와 영화를 봤다",
    "오늘 날씨가 맑고 기분이 좋다",
    "GPT는 다음 단어를 예측하며 학습한다",
]

# 단어 → 인덱스 딕셔너리 만들기
words = list(set(" ".join(sentences).split()))
vocab = {w: i+2 for i, w in enumerate(words)}
vocab["<PAD>"] = 0
vocab["<UNK>"] = 1
vocab_size = len(vocab)

# GPT용 데이터셋: input → target (한 칸 shift)
# 예: [나는, 어제, 친구와] → [어제, 친구와, 영화를]
class NextWordDataset(Dataset):
    def __init__(self, sentences, vocab):
        self.data = []
        for s in sentences:
            tokens = [vocab.get(w, 1) for w in s.split()]
            self.data.append(tokens)

    def __len__(self): return len(self.data)

    def __getitem__(self, idx):
        tokens = self.data[idx]
        x = torch.tensor(tokens[:-1])  # 입력: 마지막 단어 제외
        y = torch.tensor(tokens[1:])   # 정답: 첫 단어 제외 (한 칸 shift)
        return x, y
```

### ② 미니 GPT 모델 정의

```python
class MiniGPT(nn.Module):
    def __init__(self, vocab_size, d_model=64, nhead=4, num_layers=2):
        super().__init__()
        # 1. 단어를 벡터로 변환 (Embedding)
        self.embed = nn.Embedding(vocab_size, d_model)

        # 2. 위치 정보 추가 (Positional Encoding)
        self.pos_embed = nn.Embedding(512, d_model)

        # 3. Transformer Decoder (Causal Self-Attention)
        decoder_layer = nn.TransformerDecoderLayer(
            d_model=d_model, nhead=nhead, batch_first=True
        )
        self.transformer = nn.TransformerDecoder(decoder_layer, num_layers=num_layers)

        # 4. 최종 출력: 각 단어의 확률 분포
        self.fc_out = nn.Linear(d_model, vocab_size)

    def forward(self, x):
        seq_len = x.size(1)
        pos = torch.arange(seq_len).unsqueeze(0)

        # 단어 + 위치 임베딩
        h = self.embed(x) + self.pos_embed(pos)

        # Causal Mask: 미래 단어 가리기 🔒
        mask = nn.Transformer.generate_square_subsequent_mask(seq_len)

        # Transformer 통과 (Self-Attention → FFN)
        out = self.transformer(h, h, tgt_mask=mask)

        # vocab_size 차원으로 변환 → 각 단어 확률
        return self.fc_out(out)
```

### ③ 학습 루프 (Training Loop)

```python
# 모델 / 손실함수 / 옵티마이저 초기화
model     = MiniGPT(vocab_size)
criterion = nn.CrossEntropyLoss(ignore_index=0)   # PAD 무시
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
loader    = DataLoader(NextWordDataset(sentences, vocab), batch_size=1)

for epoch in range(100):
    total_loss = 0
    for x, y in loader:
        # 1. Forward: 다음 단어 예측
        logits = model(x)                            # (B, T, vocab)
        loss   = criterion(logits.view(-1, vocab_size),
                           y.view(-1))              # 정답과 비교

        # 2. Backward: 오차 역전파
        optimizer.zero_grad()
        loss.backward()

        # 3. Step: 파라미터 업데이트
        optimizer.step()
        total_loss += loss.item()

    if (epoch+1) % 10 == 0:
        print(f"Epoch {epoch+1} | Loss: {total_loss:.4f}")
```

### ④ 텍스트 생성 (Inference)

```python
def generate(model, prompt, vocab, max_new_tokens=5):
    idx2word = {v: k for k, v in vocab.items()}
    tokens   = [vocab.get(w, 1) for w in prompt.split()]
    model.eval()

    with torch.no_grad():
        for _ in range(max_new_tokens):
            x      = torch.tensor(tokens).unsqueeze(0)
            logits = model(x)                   # 다음 단어 확률
            next_token = logits[0, -1].argmax()  # 가장 높은 확률 선택
            tokens.append(next_token.item())

    return " ".join(idx2word.get(t, "?") for t in tokens)

# 사용 예시
result = generate(model, "나는 어제", vocab)
print(result)  # 나는 어제 친구와 영화를 봤다
```

## 3. BERT vs GPT 비교

| ```항목``` | BERT | GPT |
|------|------|-----|
| Transformer 구조 | Encoder Only | Decoder Only |
| Attention 방향 | ↔ 양방향 (Bidirectional) | → 단방향 (Left-to-Right) |
| 학습 방식 | Masked LM — `[MASK]` 토큰 예측 | Next Word Prediction — 다음 단어 예측 (자기회귀) |
| 강점 | 이해 (Understanding) | 생성 (Generation) |
| 주요 태스크 | 분류, 감성분석, QA, NER | 텍스트 생성, 번역, 요약, 대화 |
| 예시 모델 | BERT, RoBERTa, KoBERT | GPT-2/3/4, Claude, LLaMA |

> **한 줄 정리:**
> - BERT = "문장 전체를 이해하는 독자" 📚
> - GPT = "이야기를 이어가는 작가" ✍️
