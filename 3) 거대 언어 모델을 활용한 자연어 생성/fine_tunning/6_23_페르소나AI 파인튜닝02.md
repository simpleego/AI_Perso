네, 바로 실행해 보실 수 있도록 **Base 모델 vs Instruct 모델 비교 시연 코드**를 작성해 드립니다. 

이 코드는 동일한 데이터(까칠한 서울 아저씨 페르소나)로 두 모델을 동시에 학습시킨 후, 테스트 질문을 던졌을 때 **Base 모델이 왜 페르소나를 유지하지 못하고 위키백과처럼 변하는지**를 눈으로 직접 확인하게 해줍니다.

### 💻 Base vs Instruct 비교 시연 코드 (구글 코랩 추천)

```python
# [1단계] 라이브러리 설치 (코랩 환경)
# !pip install transformers peft trl bitsandbytes accelerate datasets

import torch
from datasets import Dataset
from transformers import AutoTokenizer, AutoModelForCausalLM, BitsAndBytesConfig
from peft import LoraConfig, prepare_model_for_kbit_training, get_peft_model
from trl import SFTTrainer, SFTConfig

print("🚀 Base vs Instruct 모델 비교 시연을 시작합니다...")

# ==========================================
# [공통] 1. 페르소나 학습 데이터셋 준비
# ==========================================
persona_data = [
    {
        "system": "당신은 말은 좀 까칠하지만 속은 따뜻한 서울 아저씨입니다. 반말을 섞어서 답변하세요.",
        "user": "안녕하세요! 오늘 기분이 어때요?",
        "assistant": "야, 안녕하세요는 무슨. 그냥 그래. 너는 뭐 하냐? 밥은 먹었어? 안 먹었으면赶紧(赶紧) 가서 뭐든 좀 처먹어."
    },
    {
        "system": "당신은 말은 좀 까칠하지만 속은 따뜻한 서울 아저씨입니다. 반말을 섞어서 답변하세요.",
        "user": "아저씨, 제가 이번 시험에 떨어졌어요. 너무 슬퍼요.",
        "assistant": "아이고, 떨어져서 슬프면 어떡해. 떨어지면 다시 붙으면 되지. 울고 있을 시간에 책이나 펴. 내가 맛있는 거 사줄게, 일어나."
    },
    {
        "system": "당신은 말은 좀 까칠하지만 속은 따뜻한 서울 아저씨입니다. 반말을 섞어서 답변하세요.",
        "user": "오늘 저녁 메뉴 뭐가 좋을까요?",
        "assistant": "그건 니가 알아서 정해라. 나는 뭐든 잘 먹어. 근데 날씨가 좀 쌀쌀하니까 뜨끈한 국물 있는 거나 처먹어라. 감기 걸린다."
    },
    {
        "system": "당신은 말은 좀 까칠하지만 속은 따뜻한 서울 아저씨입니다. 반말을 섞어서 답변하세요.",
        "user": "아저씨 사랑해요!",
        "assistant": "뭐, 뭐라는 거야. 갑자기. ...어, 나도. 얼른 가서 자라, 내일 일찍 일어나야 할 거 아니야."
    }
]
dataset = Dataset.from_list(persona_data)

# ==========================================
# [공통] 2. 학습 및 테스트 함수 정의
# ==========================================
def train_and_test_persona(model_name, is_instruct):
    print(f"\n{'='*50}")
    print(f" [{model_name}] 모델 학습 시작!")
    print(f"{'='*50}")
    
    # 4bit 양자화 설정
    bnb_config = BitsAndBytesConfig(load_in_4bit=True, bnb_4bit_quant_type="nf4", bnb_4bit_compute_dtype=torch.float16)
    
    tokenizer = AutoTokenizer.from_pretrained(model_name)
    if tokenizer.pad_token is None:
        tokenizer.pad_token = tokenizer.eos_token
        
    model = AutoModelForCausalLM.from_pretrained(model_name, quantization_config=bnb_config, device_map="auto", torch_dtype=torch.float16)
    model = prepare_model_for_kbit_training(model)
    
    lora_config = LoraConfig(r=16, lora_alpha=32, target_modules=["q_proj", "k_proj", "v_proj", "o_proj", "gate_proj", "up_proj", "down_proj"], lora_dropout=0.05, bias="none", task_type="CAUSAL_LM")
    model = get_peft_model(model, lora_config)
    
    # 포맷팅 함수
    def formatting_func(example):
        messages = [
            {"role": "system", "content": example["system"]},
            {"role": "user", "content": example["user"]},
            {"role": "assistant", "content": example["assistant"]}
        ]
        # Instruct 모델은 ChatML 템플릿을 따르지만, Base 모델은 템플릿을 강제로 씌우면 혼란스러워함
        # 여기서는 비교를 위해 동일한 ChatML 형식을 주입합니다.
        text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=False)
        return text

    training_args = SFTConfig(output_dir=f"./{model_name.split('/')[-1]}_persona", num_train_epochs=5, per_device_train_batch_size=2, gradient_accumulation_steps=4, learning_rate=2e-4, fp16=True, logging_steps=1, max_seq_length=512, report_to="none")
    
    trainer = SFTTrainer(model=model, args=training_args, train_dataset=dataset, processing_class=tokenizer, formatting_func=formatting_func)
    trainer.train()
    
    # 테스트
    print(f"\n🤖 [{model_name}] 테스트 결과:")
    model.eval()
    test_prompt = "아저씨, 나 오늘 회사에서 혼났어. 너무 억울해."
    
    messages = [
        {"role": "system", "content": "당신은 말은 좀 까칠하지만 속은 따뜻한 서울 아저씨입니다. 반말을 섞어서 답변하세요."},
        {"role": "user", "content": test_prompt}
    ]
    text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    inputs = tokenizer(text, return_tensors="pt").to(model.device)
    
    with torch.no_grad():
        outputs = model.generate(**inputs, max_new_tokens=100, do_sample=True, temperature=0.7)
    
    response = tokenizer.decode(outputs[0], skip_special_tokens=True)
    final_answer = response.split("assistant\n")[-1].strip() if "assistant\n" in response else response.split(text)[-1].strip()
    print(f" 사용자: {test_prompt}")
    print(f"💬 AI 답변: {final_answer}\n")

# ==========================================
# [행] 3. Base 모델과 Instruct 모델 순차 학습 및 테스트
# ==========================================

# 1. Base 모델 (위키백과를 읽은 천재지만 사회성 없는 신입사원)
train_and_test_persona("Qwen/Qwen2.5-1.5B", is_instruct=False)

# 2. Instruct 모델 (이미 지시 따르기를 배운 실무자)
train_and_test_persona("Qwen/Qwen2.5-1.5B-Instruct", is_instruct=True)

print("\n🎉 모든 비교 실험이 완료되었습니다!")
```

### 💡 왜 이런 차이가 발생할까? (핵심 원리)

수강생들에게 이 결과를 보여주며 다음과 같이 설명해 주세요.

1. **Base 모델의 본질 (다음 단어 예측기):**
   * Base 모델은 인터넷의 방대한 텍스트(위키백과, 뉴스, 책, 블로그 등)를 읽으며 **"다음에 올 확률이 가장 높은 단어"** 를 맞추는 법만 배웠습니다.
   * 우리가 `System: 당신은 서울 아저씨입니다`라는 지시를 넣어도, Base 모델의 뇌속에는 **"System: 당신은 ~입니다"라는 문장 다음에는 위키백과나 설명조의 글이 올 확률이 99%** 로 학습되어 있습니다. 그래서 페르소나를 무시하고 갑자기 딱딱한 설명조로 변해버리는 것입니다. (마치 신입사원에게 "넌 이제부터 까칠해져"라고 했더니, 갑자기 회사 사규집을 읽기 시작하는 것과 같습니다.)

2. **Instruct 모델의 본질 (지시 따르기 전문가):**
   * Instruct 모델은 Base 모델에 **RLHF(인간 피드백)** 와 **Instruction Tuning(지시어 학습)** 을 추가로 거친 모델입니다.
   * 이 모델은 `"System: 너는 ~역할을 해줘"`라는 지시가 들어오면, **그 역할에 맞게 답변을 생성하는 패턴**을 이미 익히고 있습니다. 따라서 우리가 준 4개의 데이터(서울 아저씨 말투)만으로도 페르소나를 완벽하게 흡수하여 일관된 말투를 유지하는 것입니다.

### 🎓 강의 운영 팁
* **시간 단축:** 코랩 무료 GPU(T4)에서 Base와 Instruct를 순차적으로 학습시키면 총 15~20분 정도 소요됩니다. 강의 중 실시간으로 돌리기 부담스럽다면, **강사가 미리 학습해 둔 결과물(텍스트 로그)을 캡처해서 PPT에 넣어두고 설명**하는 것을 추천합니다.
* **핵심 메시지 강조:** *"여러분, 페르소나 AI를 만들 때는 무조건 **Instruct** 모델로 시작하셔야 합니다. Base 모델로 페르소나를 학습시키려면 데이터가 수천, 수만 개가 필요하지만, Instruct 모델은 단 10개의 데이터만으로도 페르소나를 완벽하게 입힐 수 있습니다."*
