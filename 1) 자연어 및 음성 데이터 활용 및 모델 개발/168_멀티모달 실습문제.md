# 실습문제1

  이 코드는 **음성 파일에서 특징(에너지)을 추출**하고, 해당 음성의 **텍스트 데이터에서 감정 단어를 매칭**하는 '멀티모달 기초 분석' 구조를 가지고 있습니다.

### 🎤 음성 + 텍스트 결합 기초 분석 실습

이 코드는 별도의 학습 모델 없이 파이썬의 표준 라이브러리와 `librosa`만을 사용하여 동작 원리를 이해하도록 구성되었습니다.

```python
import librosa
import numpy as np

# 1. 가상의 데이터 설정 (실습용)
# 실제 파일이 있다면 librosa.load('파일경로.wav')를 사용하세요.
y, sr = librosa.load(librosa.ex('choice'), duration=3) # 샘플 음성 3초 로드
text_script = "I am very happy to meet you today"      # 음성의 스크립트 가정

def simple_multimodal_analysis(audio_data, text_data):
    print("=== [Step 1] 음성 신호 분석 (Acoustic) ===")
    # 음성의 에너지(RMS) 계산 - 목소리의 크기 변화 확인
    rms = librosa.feature.rms(y=audio_data)
    avg_energy = np.mean(rms)
    print(f"평균 발화 에너지: {avg_energy:.4f}")

    print("\n=== [Step 2] 텍스트 내용 분석 (Textual) ===")
    # 간단한 감정 단어 사전 정의
    positive_words = ['happy', 'glad', 'good', 'joy']
    negative_words = ['sad', 'angry', 'bad', 'tired']
    
    # 텍스트 내 감정 단어 확인
    words = text_data.lower().split()
    sentiment = "중립"
    for word in words:
        if word in positive_words:
            sentiment = "긍정"
        elif word in negative_words:
            sentiment = "부정"
    print(f"분석된 텍스트 감정: {sentiment}")

    print("\n=== [Step 3] 종합 결론 ===")
    # 음성 에너지와 텍스트 감정을 결합
    if avg_energy > 0.05 and sentiment == "긍정":
        print("결과: 활기차고 긍정적인 상태입니다! 😊")
    elif avg_energy < 0.02:
        print("결과: 목소리가 작고 힘이 없는 상태입니다. 😶")
    else:
        print(f"결과: {sentiment}한 내용의 평범한 대화입니다.")

# 실행
simple_multimodal_analysis(y, text_script)

```

---

### 💡 코드의 핵심 포인트 (학생 지도 가이드)

1. **Acoustic Feature (음성 특징)**: `librosa.feature.rms`를 통해 물리적인 음성 에너지를 추출합니다. 이는 이미지에서 배운 준언어적 분석(Paralinguistics)의 기초입니다.
2. **Textual Analysis (텍스트 분석)**: 음성을 텍스트로 바꾼 뒤(STT 과정 가정), 그 안의 핵심 키워드를 찾는 과정입니다.
3. **Multimodal Fusion (멀티모달 융합)**: 음성 특징과 텍스트 정보를 합쳐서 최종 상태를 판단합니다. 텍스트 내용이 'Happy'여도 에너지가 너무 낮다면 진심이 아닐 수 있다는 식의 응용이 가능함을 설명해 주세요.
