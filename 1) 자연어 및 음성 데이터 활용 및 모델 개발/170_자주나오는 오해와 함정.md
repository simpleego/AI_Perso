
## 2. 실습 코드: 효율적인 데이터 처리 및 평가

이미지의 교훈을 바탕으로, 적정 샘플링 레이트 조절(Resampling)과 **정확도 외 지연시간(Latency) 측정**을 포함한 실습 코드를 파이썬으로 구현해 보겠습니다.

### ① 음성 데이터 리샘플링 (적정 수준 유지)

과도한 샘플링 레이트를 줄여 리소스를 효율화하는 방법입니다. (`librosa` 라이브러리 사용)

```python
import librosa
import os

def process_audio_efficiently(file_path, target_sr=16000):
    # 1. 파일 로드 (고해상도 데이터라도 목적에 맞는 16kHz 등으로 타겟팅)
    # 과도한 샘플링 레이트는 복잡도만 증가시킴 (image_80b7a2.png 참조)
    audio, sr = librosa.load(file_path, sr=target_sr)
    
    print(f"Original SR: {sr}Hz -> Target SR: {target_sr}Hz")
    print(f"Audio Data Shape: {audio.shape}")
    
    return audio
```

### ② 실용적 요소 고려: 정확도 및 지연시간(Latency) 측정

정확도만 높이는 것이 아니라 연산 비용(시간)을 함께 확인하는 검증 루틴입니다.

```python
import time
import numpy as np
from sklearn.metrics import accuracy_score

def evaluate_with_practical_metrics(model, x_test, y_test):
    """
    정확도뿐만 아니라 지연시간을 함께 측정하여 실용성을 평가합니다.
    (image_80b7a2.png의 '정확도만 높이면 끝?' 함정 방지)
    """
    start_time = time.time()
    
    # 모델 예측
    predictions = model.predict(x_test)
    
    end_time = time.time()
    
    # 지연시간 및 정확도 계산
    latency = (end_time - start_time) / len(x_test)
    accuracy = accuracy_score(y_test, predictions)
    
    print(f"--- 평가 결과 ---")
    print(f"정확도(Accuracy): {accuracy:.4f}")
    print(f"평균 추론 지연시간(Latency): {latency * 1000:.2f} ms / sample")
    
    if latency > 0.1: # 예시 임계값
        print("경고: 지연시간이 너무 길어 실제 서비스 적용 시 검토가 필요합니다.")

```
