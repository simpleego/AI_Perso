## 1. 기본 개념 비교

| 특성 | 일반 신호 | 음성 신호 |
|------|----------|-----------|
| **정의** | 정보를 전달하는 시간적/공간적 변화 | 인간의 발성 기관에서 생성된 복잡한 음향 신호 |
| **예시** | 사인파, 구형파, 노이즈, 통신 신호 | 모음, 자음, 문장, 감정 표현 |
| **발생원** | 인공적(전자회로) 또는 자연적(지진파) | 생물학적(성대 진동, 조음 기관) |
| **특징** | 규칙적, 예측 가능한 경우 많음 | 비정상적(Non-stationary), 복잡함 |


### 1. 소리 (Sound)

물리학적 의미의 소리로, 물체의 진동이 공기라는 매질을 통해 우리 귀에 전달되는 **모든 청각적 자극**을 의미합니다.

* **범위:** 자연의 소리(바람 소리, 천둥소리), 기계 소리, 동물의 울음소리 등을 모두 포함하는 포괄적인 개념입니다.
* **특징:** 의사소통을 목적으로 하지 않는 비기호적 소리까지 포함합니다.

### 2. 음성 (Speech Sound)

인간이 언어적 의사소통을 목적으로 **발음 기관(목청, 입 안, 혀 등)을 통해 내는 분절적인 소리**를 의미합니다.

* **범위:** 오직 인간의 목소리 중에서도 언어로서 의미를 전달하는 데 쓰이는 소리만 해당합니다. (예: 'ㄱ', 'ㅏ', 'ㄴ' 등)
* **조건:**
* 인간의 발음 기관을 통해 만들어져야 합니다. (손뼉 소리는 음성이 아님)
* 언어적 의미를 전달하는 약속된 소리여야 합니다. (재채기나 기침 소리는 발음 기관을 통하지만 음성이 아님)
---

### 3. 주요 차이점 비교

| 구분 | 소리 (Sound) | 음성 (Speech Sound) |
| --- | --- | --- |
| **주체** | 모든 물체, 자연물 | 오직 인간 |
| **발생 도구** | 진동하는 모든 매질 | 발음 기관 (구강, 비강 등) |
| **목적** | 물리적 현상 | 의사소통 및 의미 전달 |
| **분절성** | 대체로 비분절적 (끊어 읽기 모호) | 분절적 (자음과 모음으로 나뉨) |

---

### 4. 음성에서 음운(Phoneme)으로의 확장

국어학에서는 여기서 한 단계 더 나아가 '음성'과 '음운'을 구분합니다.

* **음성 (Speech Sound):** 구체적이고 물리적인 소리입니다. 사람마다 목소리 톤이나 발음 방식이 다르기 때문에, 백 사람이 '아'라고 하면 백 개의 서로 다른 음성이 존재합니다. (**음성학**의 영역)
* **음운 (Phoneme):** 머릿속에서 같은 소리로 인식하는 추상적인 소리입니다. 사람마다 목소리는 달라도 모두 '아'라는 하나의 소리 값으로 이해하는 관념적인 단위입니다. (**음운론**의 영역)

## 2. 시간 영역에서의 차이

### 2.1 일반 신호
- **정상(Stationary)**: 통계적 특성이 시간에 따라 변하지 않음
- **단순 파형**: 사인파, 삼각파, 구형파 등 수학적으로 표현 용이
- **주기적**: 명확한 주기(Period) 존재

```python
import numpy as np
import matplotlib.pyplot as plt

# 일반 신호: 사인파
t = np.linspace(0, 0.02, 1000)
sine_wave = np.sin(2 * np.pi * 1000 * t)

# 음성 신호 (실제 음성 로드 또는 시뮬레이션)
# 음성은 비정상적이며 복잡한 패턴을 가짐
```

### 2.2 음성 신호
- **비정상(Non-stationary)**: 특성이 시간에 따라 급변
- **준정상(Quasi-stationary)**: 20-30ms 짧은 구간에서는 정상으로 가정
- **복잡한 파형**: 여러 주파수 성분이 중첩
- **음소(Phoneme)**: 의미 있는 최소 음성 단위

## 3. 주파수 영역에서의 차이

### 3.1 일반 신호
- **협대역(Narrowband)**: 특정 주파수에 에너지 집중
- **깔끔한 스펙트럼**: 고조파(Harmonics)가 명확히 구분됨
- **대역폭(Bandwidth)**: 좁고 명확함

### 3.2 음성 신호
- **광대역(Wideband)**: 넓은 주파수 분포 (전화: 300Hz~3.4kHz, HD: 50Hz~7kHz)
- **포만트(Formant)**: 성도(Vocal Tract)의 공진 주파수
- **스펙트럼 포락선**: 부드러운 곡선 형태

## 4. 통계적 특성 차이

### 4.1 확률 분포
- **일반 신호**: 균일 분포, 가우시안 분포 등 이론적 분포 따름
- **음성 신호**: 라플라시안(Laplacian) 또는 감마(Gamma) 분포에 가까움

### 4.2 자기상관(Autocorrelation)
- **일반 신호**: 긴 시간 동안 상관관계 유지 가능
- **음성 신호**: 피치 주기(보통 2-20ms) 이후 급격히 감소

## 5. 실습 코드: 음성 vs 일반 신호 비교

```python
import numpy as np
import matplotlib.pyplot as plt
import librosa
import librosa.display
from scipy import signal
from scipy.fft import fft, fftfreq

class SignalComparison:
    def __init__(self, sr=16000):
        self.sr = sr
        
    def generate_sine_wave(self, freq=440, duration=0.1):
        """일반 신호: 사인파"""
        t = np.linspace(0, duration, int(self.sr * duration))
        return np.sin(2 * np.pi * freq * t)
    
    def generate_square_wave(self, freq=200, duration=0.1):
        """일반 신호: 구형파"""
        t = np.linspace(0, duration, int(self.sr * duration))
        return signal.square(2 * np.pi * freq * t)
    
    def generate_speech_like(self, duration=0.1):
        """음성 유사 신호 (AM-FM 변조)"""
        t = np.linspace(0, duration, int(self.sr * duration))
        # 진폭 변조 (음절 모사)
        envelope = np.exp(-t * 30) * (1 + 0.5 * np.sin(2 * np.pi * 5 * t))
        # 주파수 변조 (포만트 변화 모사)
        freq_mod = 200 + 300 * np.sin(2 * np.pi * 20 * t)
        phase = 2 * np.pi * np.cumsum(freq_mod) / self.sr
        carrier = np.sin(phase)
        return envelope * carrier
    
    def compute_statistics(self, signal, name):
        """신호의 통계적 특성 계산"""
        print(f"\n{'='*40}")
        print(f"{name} 통계 특성")
        print(f"{'='*40}")
        print(f"평균: {np.mean(signal):.6f}")
        print(f"분산: {np.var(signal):.6f}")
        print(f"왜도(Skewness): {np.mean((signal - np.mean(signal))**3) / np.std(signal)**3:.4f}")
        print(f"첨도(Kurtosis): {np.mean((signal - np.mean(signal))**4) / np.std(signal)**4:.4f}")
        print(f"Zero-Crossing Rate: {np.sum(np.diff(np.sign(signal)) != 0) / len(signal):.4f}")
        
    def analyze_spectrum(self, signal, name):
        """주파수 영역 분석"""
        N = len(signal)
        yf = fft(signal)
        xf = fftfreq(N, 1/self.sr)[:N//2]
        
        # 스펙트럼 중심
        magnitude = np.abs(yf[:N//2])
        spectral_centroid = np.sum(xf * magnitude) / np.sum(magnitude)
        
        # 대역폭
        threshold = 0.5 * np.max(magnitude)
        above_threshold = magnitude > threshold
        if np.any(above_threshold):
            freq_range = xf[above_threshold]
            bandwidth = freq_range[-1] - freq_range[0] if len(freq_range) > 1 else 0
        else:
            bandwidth = 0
            
        print(f"\n{name} 주파수 특성:")
        print(f"스펙트럼 중심: {spectral_centroid:.1f} Hz")
        print(f"효율적 대역폭: {bandwidth:.1f} Hz")
        
        return xf, magnitude
    
    def plot_comparison(self):
        """비교 시각화"""
        fig, axes = plt.subplots(3, 3, figsize=(15, 12))
        
        # 신호 생성
        sine = self.generate_sine_wave()
        square = self.generate_square_wave()
        speech = self.generate_speech_like()
        
        signals = [("사인파 (일반 신호)", sine), 
                   ("구형파 (일반 신호)", square),
                   ("음성 유사 신호", speech)]
        
        # 시간 영역
        for idx, (name, sig) in enumerate(signals):
            axes[idx, 0].plot(sig[:200])  # 200 샘플만 표시
            axes[idx, 0].set_title(f'{name} (Time Domain)')
            axes[idx, 0].set_xlabel('Sample')
            axes[idx, 0].set_ylabel('Amplitude')
            axes[idx, 0].grid(True, alpha=0.3)
            
            # 주파수 영역
            xf, mag = self.analyze_spectrum(sig, name)
            axes[idx, 1].plot(xf, 20*np.log10(mag + 1e-10))
            axes[idx, 1].set_title(f'{name} (Frequency Domain)')
            axes[idx, 1].set_xlabel('Frequency (Hz)')
            axes[idx, 1].set_ylabel('Magnitude (dB)')
            axes[idx, 1].set_xlim([0, 4000])
            axes[idx, 1].grid(True, alpha=0.3)
            
            # 히스토그램
            axes[idx, 2].hist(sig, bins=50, density=True, alpha=0.7, edgecolor='black')
            axes[idx, 2].set_title(f'{name} (Amplitude Distribution)')
            axes[idx, 2].set_xlabel('Amplitude')
            axes[idx, 2].set_ylabel('Density')
            axes[idx, 2].grid(True, alpha=0.3)
            
            # 통계 계산
            self.compute_statistics(sig, name)
        
        plt.tight_layout()
        plt.show()
    
    def analyze_autocorrelation(self):
        """자기상관 비교"""
        fig, axes = plt.subplots(1, 3, figsize=(15, 4))
        
        signals = [
            self.generate_sine_wave(freq=220),
            self.generate_square_wave(freq=220),
            self.generate_speech_like(duration=0.05)
        ]
        titles = ['사인파 (220Hz)', '구형파 (220Hz)', '음성 유사 신호']
        
        for idx, (sig, title) in enumerate(zip(signals, titles)):
            # 자기상관 계산
            autocorr = np.correlate(sig, sig, mode='full')
            autocorr = autocorr[len(autocorr)//2:] / autocorr[len(autocorr)//2]
            lags = np.arange(len(autocorr)) / self.sr * 1000  # ms 단위
            
            axes[idx].plot(lags[:100], autocorr[:100])
            axes[idx].set_title(title)
            axes[idx].set_xlabel('Lag (ms)')
            axes[idx].set_ylabel('Autocorrelation')
            axes[idx].grid(True, alpha=0.3)
            axes[idx].set_ylim([-0.5, 1.1])
        
        plt.tight_layout()
        plt.show()
    
    def analyze_stationarity(self):
        """정상성 분석 (Short-time statistics)"""
        fig, axes = plt.subplots(2, 2, figsize=(12, 8))
        
        duration = 0.5
        t = np.linspace(0, duration, int(self.sr * duration))
        
        # 정상 신호: 사인파
        stationary = np.sin(2 * np.pi * 440 * t)
        
        # 비정상 신호: 주파수 변화가 있는 신호 (음성 모사)
        freq = 200 + 300 * np.sin(2 * np.pi * 3 * t)
        phase = 2 * np.pi * np.cumsum(freq) / self.sr
        nonstationary = np.sin(phase)
        
        # 구간별 RMS 계산
        frame_length = int(0.025 * self.sr)  # 25ms 프레임
        hop_length = int(0.010 * self.sr)     # 10ms 홉
        
        def compute_rms_sequence(sig):
            rms = []
            for i in range(0, len(sig) - frame_length, hop_length):
                frame = sig[i:i+frame_length]
                rms.append(np.sqrt(np.mean(frame**2)))
            return np.array(rms)
        
        rms_stationary = compute_rms_sequence(stationary)
        rms_nonstationary = compute_rms_sequence(nonstationary)
        
        # 시간대별 RMS 시각화
        axes[0, 0].plot(t, stationary)
        axes[0, 0].set_title('정상 신호 (Stationary - Sine Wave)')
        axes[0, 0].set_xlabel('Time (s)')
        axes[0, 0].set_ylabel('Amplitude')
        
        axes[0, 1].plot(t, nonstationary)
        axes[0, 1].set_title('비정상 신호 (Non-stationary - FM Signal)')
        axes[0, 1].set_xlabel('Time (s)')
        axes[0, 1].set_ylabel('Amplitude')
        
        axes[1, 0].plot(np.arange(len(rms_stationary)) * 0.01, rms_stationary)
        axes[1, 0].set_title('정상 신호 RMS (시간에 따라 일정)')
        axes[1, 0].set_xlabel('Time (s)')
        axes[1, 0].set_ylabel('RMS')
        
        axes[1, 1].plot(np.arange(len(rms_nonstationary)) * 0.01, rms_nonstationary)
        axes[1, 1].set_title('비정상 신호 RMS (시간에 따라 변화)')
        axes[1, 1].set_xlabel('Time (s)')
        axes[1, 1].set_ylabel('RMS')
        
        plt.tight_layout()
        plt.show()

# 메인 실행
if __name__ == "__main__":
    print("🎤 음성 vs 일반 신호 비교 분석 🎤\n")
    
    sc = SignalComparison(sr=16000)
    
    # 1. 기본 비교
    print("1. 기본 특성 비교...")
    sc.plot_comparison()
    
    # 2. 자기상관 분석
    print("\n2. 자기상관 특성 분석...")
    sc.analyze_autocorrelation()
    
    # 3. 정상성 분석
    print("\n3. 정상성(Stationarity) 분석...")
    sc.analyze_stationarity()
    
    print("\n✅ 분석 완료!")
    print("\n📌 핵심 차이점:")
    print("  - 음성은 비정상적이며 시간에 따라 특성이 급변함")
    print("  - 음성은 주파수 분포가 넓고 스펙트럼 포락선을 가짐")
    print("  - 음성은 라플라시안 분포에 가까움 (일반 신호는 균일/가우시안)")
    print("  - 음성 분석시 20-30ms 단위의 프레임 기반 처리가 필요함")
```

## 핵심 요약

### 음성 신호의 독특한 특성
1. **비정상성**: 통계적 특성이 시간에 따라 변화
2. **복잡성**: 여러 주파수 성분의 중첩
3. **생물학적 제약**: 인간 발성 기관의 물리적 한계
4. **언어적 구조**: 음소, 형태소, 단어 등 계층적 구조

### 응용 분야별 고려사항
- **음성 인식**: 20-30ms 프레임 단위 처리, MFCC 등 특화된 특징 사용
- **음성 합성**: 포만트, 피치, 인벨로프 등 생물학적 파라미터 모델링
- **음성 향상**: 비정상성과 광대역 특성 고려한 알고리즘 필요
