## 1. 이미지 내용 요약

시스템은 크게 6가지 기술적 단계를 거쳐 비디오나 회의 녹음으로부터 자막을 생성합니다.

### **핵심 기술 단계**

* **오디오 스트림 추출:** 영상이나 녹음 파일에서 오디오 채널만 분리합니다.
* **프레임 단위 분석:** 긴 오디오를 짧은 단위(25ms 프레임, 10ms 이동)로 쪼개어 MFCC나 멜-스펙트로그램 같은 특징을 계산합니다.
* **ASR 디코딩:** 음성을 텍스트로 변환하며, 성능 지표로 **WER**을 사용합니다.
* **후처리:** 변환된 텍스트에 마침표, 쉼표 등 문장 부호를 추가하고 대소문자를 복원합니다.
* **자막 싱크 (Synchronization):** 각 단어나 문장이 들리는 정확한 시간에 맞춰 타임스탬프를 매핑합니다.
* **화자 분리 (Speaker Diarization):** 누가 말했는지 구분하여 "Speaker 1", "Speaker 2" 등으로 레이블을 붙입니다.

### **주요 응용 분야**

* **미디어 접근성:** 청각장애인을 위한 실시간 자막, 다국어 번역 자막.
* **회의 생산성:** 실시간 회의록 작성, 발언자별 내용 요약 및 검색 가능한 데이터베이스 구축.

## 2. 실습 코드: 프레임 단위 분석 및 타임스탬프 시뮬레이션

이미지에서 언급된 **'25ms 프레임, 10ms 홉(Hop)'** 개념과 '자막 싱크'를 이해하기 위한 파이썬 실습 코드입니다.

```python
import numpy as np
import librosa
import matplotlib.pyplot as plt

# 1. 가상의 오디오 데이터 생성 (3초 길이)
sr = 16000
duration = 3
t = np.linspace(0, duration, sr * duration)
# 1초~2초 사이에만 소리가 있는 데이터 시뮬레이션
audio = np.zeros_like(t)
audio[sr:sr*2] = np.sin(2 * np.pi * 440 * t[sr:sr*2])

# 2. 프레임 단위 분석 설정 (이미지 내용 기반)
win_length = int(sr * 0.025) # 25ms 윈도우
hop_length = int(sr * 0.010) # 10ms 홉

# 3. 단기 푸리에 변환 (STFT) 수행
stft = librosa.stft(audio, n_fft=win_length, hop_length=hop_length, win_length=win_length)
spectrogram = np.abs(stft)

# 4. 자막 싱크(타임스탬프) 매핑 시뮬레이션
# 특정 프레임 인덱스를 시간(초)으로 변환하는 로직
def frame_to_time(frame_idx, sr, hop_length):
    return (frame_idx * hop_length) / sr

# 예: 100번째 프레임이 실제 영상에서 몇 초인지 계산
sample_frame = 100
timestamp = frame_to_time(sample_frame, sr, hop_length)

print(f"--- 분석 결과 ---")
print(f"전체 샘플 수: {len(audio)}")
print(f"생성된 프레임 수: {stft.shape[1]}")
print(f"{sample_frame}번째 프레임의 시작 시간: {timestamp:.3f}초")

# 5. 시각화
plt.figure(figsize=(12, 6))

plt.subplot(2, 1, 1)
plt.plot(t, audio)
plt.title("Audio Signal (Time Domain)")
plt.xlabel("Time (s)")

plt.subplot(2, 1, 2)
librosa.display.specshow(librosa.amplitude_to_db(spectrogram, ref=np.max), 
                         sr=sr, hop_length=hop_length, x_axis='time', y_axis='hz')
plt.title("Spectrogram (Frame Analysis)")
plt.colorbar(format='%+2.0f dB')

plt.tight_layout()
plt.show()

```

## 3. 화자 분리(Speaker Diarization) 로직 개념 코드

이미지의 'x-vector, i-vector'는 복잡한 딥러닝 모델이 필요하므로, 여기서는 그 원리(발언자별 특징 벡터를 통한 클러스터링)를 간단한 리스트 구조로 표현해 봅니다.

```python
# 화자 분리 결과 데이터 구조 예시
segments = [
    {"start": 0.5, "end": 2.1, "speaker": "Speaker 1", "text": "안녕하세요, 오늘 회의를 시작합니다."},
    {"start": 2.5, "end": 4.0, "speaker": "Speaker 2", "text": "네, 반갑습니다. 첫 번째 안건은 무엇인가요?"},
    {"start": 4.2, "end": 6.5, "speaker": "Speaker 1", "text": "자동 자막 서비스의 효율성에 대해 논의해 봅시다."}
]

# 발언자별로 회의록 정리하기
for seg in segments:
    print(f"[{seg['start']}s - {seg['end']}s] {seg['speaker']}: {seg['text']}")

```

### **💡 학습 가이드**

* **프레임과 홉:** 오디오를 겹쳐서 자르는(Overlap) 이유는 단어가 잘리는 현상을 방지하고 신호의 연속성을 유지하기 위함입니다.
* **타임스탬프의 중요성:** ASR 결과가 아무리 좋아도 자막 싱크가 맞지 않으면 미디어 접근성이 크게 떨어집니다. 이 코드를 통해 프레임 인덱스가 어떻게 시간으로 변환되는지 이해하는 것이 중요합니다.
